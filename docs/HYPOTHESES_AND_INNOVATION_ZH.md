# 候选改进、先验撞车与可证伪条件

本文件记录实验前的想法，不代表新颖性或性能已经成立。

## 核查后的研究空间

[EAT](https://arxiv.org/abs/2509.26522) 已使用强制思考结束后的熵及 EMA 稳定性；[Conformal Thinking](https://arxiv.org/abs/2602.03814) 已包含“足够自信”和“继续也很难成功”的双阈值停止。因此，聊天中把现有方法统一概括成只会“越自信越早停”是不准确的。[ASAG](https://arxiv.org/abs/2606.15070) 已有早停、logits 引导、跳转提示与原样继续四种策略，不能把“多动作”三个字当作差异化。[REFRAIN](https://arxiv.org/abs/2510.10103) 已研究反思冗余检测及自适应阈值。此次未找到可靠的 ASAG/REFRAIN 官方可执行代码入口；不能把别人报告的指标当成本地复现。

## 可检验候选

1. **显式动作净收益代替当前答案正确性。** 分别学习 STOP、一步、FULL 的价值，用期望准确率增量减去条件计算成本进行决策。对照长度、单置信度、单熵、当前正确率模型及强停止基线。若不能超过这些对照，公式本身没有贡献。
2. **把有益纠错与有害反转分开。** 两头模型估计指定共同随机数耦合下的两种事件，但事件联合概率会随随机耦合而变。其差值的期望等于动作边际正确率差，具有耦合不变性。增加独立动作正确率模型作为对照，重复采样检查结论是否只来自一种随机配对方式。
3. **条件成本和稀疏决策。** 用廉价特征估计一步/FULL 的剩余 token，而非永久使用同一个平均成本；已经选 FULL 时不再继续收集无用特征。真正收益必须包含决策器耗时。对检测频率的改进必须与同质量的固定频率策略消融。
4. **风险控制与经验性能分开。** 工程集选择经验 operating point，同时保存有限网格校正后的风险上界。50 题校准集不能支持任意严格的 1pp 保证；缺乏统计功效不能包装成无损。

## 本轮不预先宣称的结论

统一短答案格式、缓存复制和修复数学判分都是实验基础设施。较原版 greedy 脚本的结果变好，可能只是协议改善。真正主比较要使用相同模型精度、采样、终止和评分，且最终测试不能用于挑阈值。

若收益预测被温度采样噪声淹没，应优先测动作边际收益的置信区间、分析校准和特征不足；若预测有信息而在线无加速，应分析检测频率、错误动作、收益抵消和运行时开销。只有经过同输入重跑与消融支持的原因才写成已确认机制，其余保留为猜测。
