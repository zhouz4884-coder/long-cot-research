## 3. 上游代码审核发现

原版采用 greedy，seed 主要影响题目选择；固定预算通过文本重建前缀，未保留原生成 token IDs；其稳定停止和成本分析主要是事后模拟，不能作为真实在线加速。

三个确定性 CPU 反例证实了答案提取问题：嵌套 `\frac{1}{2}` 被截成 `\frac{1`，`\sqrt{2}` 被截断，两个 boxed 答案取到了较早的那个。这是解析器正确性诊断，**不是模型任务准确率**。见 `provenance/baseline_parser_audit.json`。

另一个条件性风险经过实测被排除：本次冻结 Qwen3 tokenizer 在 `skip_special_tokens=True` 时仍保留 `</think>`，因此不能把“结束标记被删掉”写成本次已确认的 bug。完整审计见 `BASELINE_AUDIT_ZH.md`。

## 4. 真实数值结果与失败归因

初版缓存测试要求最大绝对 logit 差 ≤0.25。五个 BF16 样本的最大差分别为 0.5、0.4375、0.375、0.4375、0.375，因而失败；但对应受控的后续 16-token 输出全部相同。

随后加入独立对照：同路径重复最大差为 0；FP32 完整/分块前缀的最大差约 `3.9e-5–4.7e-5`。在真实思考前缀上，BF16 相对 L2 仍有约 1.2% 的案例，未满足新的 1% 判据，未将其强行放行。

改用 FP16 后，已展示样本的最大 logit 差约 0.03–0.05，相对 L2 约 0.08%–0.21%；五组概率分布和受控生成检查通过。另一个真实状态深拷贝检查确认：父缓存长度及 key tensor 不被子分支修改，两个同状态副本的受控续写一致。

**有证据支持的原因：** BF16 与 FP32 对照支持浮点计算路径误差，而不是明显的缓存位置错误。**尚不能推出：** 任意长上下文、任意状态都完全等价。这些检查也不能代替目标任务评估。原始失败和修订依据见 `NUMERICAL_ADMISSION_ZH.md`。

## 5. 真实答案格式失败及修复

工程题 `test/precalculus/441.json` 的最小夹角答案是 30 度。第一条实际轨迹到达 4096 思考 token 上限；仅追加结束思考标记后，模型又从头写推导，192 个答案 token 内没有最终答案。旧评分流程从中间式提取了数字 6，却给出 `parse_status=ok`。

在**同一保存前缀**上改用统一 boxed 提示，模型首先输出 `30}`，Math-Verify 判对；在该题 128-token 的真实 KV 检查点上也观察到这个答案。这个受控例子说明答案提取提示会显著影响标签，不能把格式失败当成“需要更多思考”的数学机制证据。

后续本地代码进一步规定：在首个完整外层 boxed 闭合时结束答案，保留 192-token 硬上限；所有主方法及对照共用这个规则。**这一最新短答案停止改动尚未完成 GPU 验收，不能声称已经取得 token 或延迟收益。** 缺少完整最终答案的推导被单独记为解析失败。

这只是一个工程题的诊断，不是准确率提升、早停普适有效或论文创新的证据。统一格式之后必须对照零思考和固定预算。见 `ANSWER_PROTOCOL_ZH.md`。

## 6. 成本观察

原版第一条 generate 调用实际生成 2562 token，耗时 147.694 秒，约 17.35 token/s。这是单次原版运行的测量，不是服务器通用吞吐量，也不能据此宣称完整基准耗时。

后续主采集器使用同一实际父 KV 的串行副本展开 STOP/STEP，未干预的父轨迹作为 FULL；分支采集与复制开销单独记录。在线控制器直接执行动作并计时，不能把离线分支开销忽略后宣称在线加速。当前尚无在线 wall-clock 对比数据。

## 7. 面向高水平论文的候选改进

已有工作对该题的覆盖很强：[EAT](https://arxiv.org/abs/2509.26522) 有结束思考后的熵信号，[Conformal Thinking](https://arxiv.org/abs/2602.03814) 有置信与无望继续的双阈值，[ASAG](https://arxiv.org/abs/2606.15070) 已有多种生成干预，[REFRAIN](https://arxiv.org/abs/2510.10103) 已检测反思冗余。仅换公式、检测反思词或提出“多动作”不足以构成贡献。

本轮写入待检验代码的候选是：分别估计有益纠错与有害反转，同时用各动作边际正确率作耦合不变的对照；根据廉价特征估计剩余成本；在选择 FULL 后停止无用检测。分组交叉验证、同题消融和独立在线对照将决定它们是否有额外信息及净收益。

**原因猜测：** 早期状态可能已能输出正确候选，但自然验证仍继续；也可能只是简单题、强制提示或特定随机种子的个例。重复采样和分难度统计才能区分。若净收益预测弱，应分析标签方差、动作定义及特征不足；若离线有效而在线无收益，应检查误停止、检测频率与实际开销。

这些是研究假设和改进路径，尚未取得实验支持。候选创新的完整边界见 `HYPOTHESES_AND_INNOVATION_ZH.md`。
