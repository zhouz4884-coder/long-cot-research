# 冻结分层划分下的风险审计

## 发现与决定

v4划分按学科×floor(难度/2)在组内洗牌、不放回分配开发/选择/校准/测试，不能直接把795个校准样本视为IID二项试验。条件于开发和选择后，剩余1857题有33层，795题校准、1062题测试；两题所在层没有校准样本。只读取冻结设计元数据，没有读取测试输出或人工查看测试题干。划分不改动。

以前原型中的Clopper–Pearson界保留为**IID假设下的敏感性结果**，不作为当前设计的无条件部署认证。新的设计审计针对这批固定测试池，另明确固定逐题潜在结果、指定种子/执行协议及层内均匀随机抽样假设；不推出新任务、其他模型或未来服务分布的保证。

## 界的构造

对一个在看校准结果前冻结的策略，令剩余第g层有N_g题，其中n_g题被抽入校准，整层未知有害数M_g。校准有害数X_g的分布为Hypergeom(N_g,M_g,n_g)。该不放回分布的概率质量函数与参数定义见[官方SciPy文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.hypergeom.html)。不放回采样与IID浓缩界的区别可参见[Bardenet与Maillard，Bernoulli 2015](https://arxiv.org/abs/1309.4029)；下面是本实验的有限离散设计推导，不声称复现该论文的具体定理。

观察总校准有害数h，检验总池有害数至少为M的假设。对任意负lambda，Markov给出：

`P(sum X_g <= h) <= exp(-lambda*h) * max_{sum M_g=M} product_g E[exp(lambda*X_g)]`。

用动态规划对所有整数M_g分配取最坏情况，每层MGF按超几何PMF求和；在预声明有限负lambda网格中取最小上界。h=0时直接用精确有理数计算并最大化所有层的零事件概率，不需要Chernoff近似。无校准层不能被删除，其有害可以被完全隐藏。

欲认证测试池有害率<=epsilon，允许数为floor(epsilon*1062)，取检验M=h+允许数+1。更大的总有害数只使校准低尾概率更小。通过反演单调低尾检验得到覆盖：若错误认证，而真实M至少为此门槛，则该错误事件包含在一个概率不大于alpha的低尾拒绝区域内。该范围只涉及固定保留池，不是开放分布保证。数值实现记录保守1e-12余量。

## 在校准之前确定多重比较

仅做设计可行性计算，假设h=0：1pp对应测试最多10害，零事件最坏概率约0.01096415。八个等分alpha=.00625的候选即便零害，也不能按本界认证1pp；不能用原IID表掩盖此问题。2pp对应最多21害，零事件最坏概率约0.00002377。上述数字不是模型结果。

因此在选择集上预定一个主策略，最多保留7个诊断候选。K>1时主策略分配alpha=.04，剩余候选等分.01，总预算.05；K=1用.05。主策略要求预测当前正确率门槛>=.9，再优先从选择集经验有害<=1%、配对准确率下降<=1pp的策略中按成本代理选择；没有此类候选则选最少有害的质量优先诊断端点并标记选择门槛未通过。这里的.9只是预测分数门槛，不是逐题正确率保证。无当前正确率门槛的策略只作消融，避免主策略专靠两种方法都错误的题获得表面大节省。主策略身份、候选全集和alpha分配都在校准生成之前冻结，不在看到校准结果后交换主策略。2pp为预声明次要运行点，不能替换失败的主1pp目标。

## 验证范围

三个CPU方法检查用小有限总体直接枚举所有抽样子集与所有有害配置，核对低尾上界、未抽层隐患及错误认证概率。它们检验统计程序与推导的一致性，不是新模型性能。实测校准结果尚未产生；目前只有设计可行性文件 `provenance/calibration_design_audit.json`。银行的有限在线一致性检查也不等于跨运行环境的普遍不变性证明，最终结论保留这些假设。
