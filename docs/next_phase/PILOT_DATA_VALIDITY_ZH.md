# Pilot 输入有效性审查

此文记录实际审阅已生成 pilot 时发现的问题；不查看新最终测试的模型输出，不按算法效果排除题目。

## 未说明位置的几何点

pilot_index13，`omni/5d9dd6ba0a793fb38cf6`：题干给出 PQR 在 P 直角、PR=12、SQ=11、SR=13，要求 QRS 周长；未说明 S 在 PQ 上。参考解答直接使用 PS+SQ=PQ，是题干没有给出的条件。模型输出44与参考一致，按原冻结评分为正确，但文本问题不能唯一推出44。

反例：P=(0,0)、R=(0,12)、Q=(16,0)、S=(5,0) 满足所有已给条件，周长44。另取 Q=(12,0)、S=(7−√142/2,5−√142/2)，同样 SQ=11、SR=13，而 QRS 周长为24+12√2。两者均符合给出的文本，却产生不同答案。

因此这题只能用于原版本数据质量诊断，不能支撑自包含文本数学主结果。它可能原本有图像，但本次输入未提供。单纯 Gold 能解析为数字不足以验收数据有效性。

## 全体候选题的前置筛查

新增与 Gold、模型输出无关的预声明文本规则：排除未提供图片的 figure/diagram 等引用；几何题检查大写点标签是否有明确独立介绍或题设中的初始三角形定义。没有通过的条目单独保留理由。该自动规则仍不能证明每道题都适定，之后继续对 pilot、争议样本和随机样本审查。

正式开发/选择/校准/测试尚未生成，规则可在此阶段统一应用并冻结版本2，保留原版本1和100题pilot。不得把排除这题带来的评分变化作为新方法提升；不得只排除某个算法出错的题。

## 数值抽取不等于完整答案是数值

pilot_index20 的原参考是多组无限整数解：`(2,6), (2^k−1,2), (1,n) ... n≥1`，Math-Verify 抽取到末尾的1。模型只答 `a=1`，原v3评分为正确，但它没有回答完整解族。pilot_index24 的参考是“十进制展开没有0的整数”，被抽取成数字10。两例证实，Gold自己与自己解析后相等，并不能证明完整Gold是一个数值。

因此版本3增加整个Gold表面的纯数值表达式语法筛查，拒绝散文、自由字母、关系、列表/多值和未支持的文字命令；公式分数、平方根、二项式、π等保留，再结合原有限常数解析。该规则统一应用于全部正式候选，未使用其模型效果，排除260题。最终正式pool2687：dev537、selection268、cal806、test1076；旧版本1/2与原100题pilot全保留。pilot中10项输入/答案类型问题单列，原始生成和原评分保留，不将排除后的分数增量当方法提升。

还对硬币计数、时钟、六边形和未定义S的反例进行了独立的精确CPU枚举/坐标核查。这支持特定题目的Gold/有效性判断，不是GPU模型实验、整体判分准确性证明或新算法成绩。
