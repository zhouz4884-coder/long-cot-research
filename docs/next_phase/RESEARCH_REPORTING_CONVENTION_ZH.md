# 研究汇报约定

2026-11-06，依据用户本次明确要求。后续每轮先把判断说清楚，不只给实验分数或下一步方案。

1. **总目标与当前子问题。** 总目标是长思维链解题质量；写明当前解决哪个可观察失败，为什么值得做。
2. **所处阶段与实际进度。** Phase/子阶段、已实现/已跑/未完成分列，机制控制不替代自然算法或正式benchmark。
3. **逐条回应外部建议。** 用“采纳、修改后采纳、暂缓、不采纳”标记，并给理由、需要的条件和能证伪的对照。附件中的预测不当成用户要求或实测事实。
4. **方法与数据结论。** 简述模块做什么、与强baseline差在哪；报告完整分母、重复/相关样本、正常结束/触顶/未解析、成本和未执行项。
5. **自己的判断。** 哪些结果支持什么、不能支持什么；效果不好记录问题、实际尝试、未证实猜想与下一最小区分检查。

允许根据证据改变定位，不预设某个模块必须赢。单列完整系统对照和同信息/同工具组件对照，不能只挑较弱baseline汇报收益。不为填满预算而续跑，不恢复定时任务或旧长队列。
