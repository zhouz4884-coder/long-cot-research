### 重要已观测证据

1. **长期预算效应**：共同29题 boxed1024/2048/4096/8192/16384正确10/11/13/17/22，触顶27/24/22/14/11；8192→16384新增5正确、0反向，精确McNemar双侧p=0.0625；pilot不能称总体显著。
2. **参考协议敏感性**：native8k/16k为13/18正确，boxed为17/22，两个预算native均比boxed少4题；两例native思考已闭合但最终答案遭总配额截断。两个协议延长预算都提升5题，但改善题目集合几乎不同，不可归因为单一cue。
3. **短段落不等于纠错**：22题39状态、351个续写分支、1170次读出：按题等权相对STOP的DEFER1 −1.01pp，DEFER4 −1.26pp，FULL8192 +13.89pp；短续写增量思考时间5.12/18.81秒，FULL增量258.78秒；这不是在线新策略收益，且FULL117分支中72触顶。
4. **读出准入类型覆盖缺陷**：1170次读出中旧schema拒绝30次，含14个正确的 `1/7!`；修复后拒绝15次，正确表达式误拒绝0。修复未增加模型正确答案数，值得监测提高安全提交覆盖的在线收益。
5. **旧离线风险排序有限**：在旧211个实际STOP状态，`full_fix` harmful AUC .633，`1-p_stop` AUC .702。只用p_stop <.9回退的保存输出拼接代理达到266/300、时间节省代理10.88%，非真实GPU策略；Gold oracle只回退25个harmful达到273/300、时间代理35.07%，不可部署。旧独立概率头违反联合一致性：18个`full_fix>1-p_stop`、1个`full_harm>p_stop`，边际收益两个计算方式平均差.0295、最大.1693。
6. **显存验收**：新的16k candidate actual peak allocated14.63 GiB，ASAG scratch probe16k为17.03 GiB，父KV身份控制通过；`nvidia-smi`保留显存不能直接替代活跃张量峰值。无法推断batch4安全或成本固定。
7. **统计合规**：v4剩余校准+test池1857，33层，2题所在层无cal样本；已有有限分层抽样风险审计与固定family alpha（主.04、其余.01），真实校准风险结果尚未产生；证书仅针对冻结有限测试池的条件假设，不能泛化为部署任意分布。

## 2. 重新确定研究问题

**首要优化问题**：当前推理检查点上，怎样在有界16k参考的质量损失约束下，选择**提交当前被检查的答案**、**廉价再次读出/核对**或**保留长程推理机会**，使真实请求耗时最低？

**首轮创新假设（待验证）**：读出错误与尚未完成的长程计算有不同的成本和可修复性。若能够在当前候选身份绑定下区分“读出不稳”与“长程仍有收益”，则可以在不默认多分支的情况下改善正确率—耗时Pareto。

**反证点**：若固定预算/DEER试答/简单p_stop阈值在相同质量下占优，复杂条件计算无额外价值；若短步不改变质量，不开发以STEP纠错为主的控制器；若16k FULL仍显著触顶，风险证书只能写为“相对有界16k参考”。

主目标：

\[\min_{\pi\in\Pi}\;\mathbb E[T_\pi] \quad\text{s.t.}\quad \mathbb E[Y_{B=16384}-Y_\pi]\le 0.01.\]

同时独立报告 \(H_\pi=P(Y_{16384}=1,Y_\pi=0)\) 和安全提交覆盖，不将预测概率校准宣称为逐题保证。

## 3. 机制设计：逐级推进，不提前堆复杂动作

### M1：已冻结的 Candidate-Bound Quality Admission（第一优先）

- 真实侧读出生成候选A0并冻结ID、tokenIDs与最终交付字符串；检查的A0就是COMMIT交付的A0，不再重抽B。
- 首轮仅 COMMIT 或 bounded FULL16384。完整候选数值类型、预测当前正确率和相对FULL有害风险构成质量准入；成本只在准入后排序。
- 保留联合四态概率（00/01/10/11）和分立头对照；修复联合不一致本身属于必要统计建模，不预先声明原创。
- 观察质量分层下的提交覆盖率、25 harmful类型的迁移、非正确FULL子集的节省和主方法实时延迟。
- 如果单次廉价读出的质量覆盖足够且真实在线超过强固定预算，可再展开新模块。

### M2-A：固定候选的廉价重读（仅在M1之后）

- 重新读出使用相同思考前缀，不新增推理内容；保留候选A0身份；对新候选的取舍/多数票在选择集事先冻结，避免用Gold选A。
- 对比一次读出、重复读出2/3次、按当前正确率拒绝、DEER-PRo式试答；必须把被拒读出生成token、prefill和分支实际时间计费。
- 修复价值要从新的、独立的题目和读出/推导交叉种子估计，不能仅凭schema修复让14个候选通过就说质量提高。

### M2-B：长程推理机会识别（不是DEFER1/4直接纠错）

- 先在新数据估计未来到正确答案的预算—修复曲线，记录1024/2048/4096/8192/16384与自然终止、触顶、最终答案正确性。
- 因现有短动作平均收益不正，先不训练3/4动作网络；可对已知难题在有界长预算上研究是否值得继续。
- 只在M1或M2-A证明质量—成本可行且恢复时间可预测时引入稀疏检查点、长程继续的成本/完成概率估计。
- 对“答案一致但推理未完成”的状态执行单独控制：不要把重复读出一致直接理解为数学完成性；有额外验证器时计入它的成本。

### M3：风险与执行优化（M2产生净收益后）

- 使用预冻结策略在795题独立校准，主risk目标1pp，2pp明确为次要目标；有限池证书与IID敏感性报告分列。
- 调度/缓存只优化真在线链路：从父KV分出side candidate、batch1/2/4微基准、可复用长程主分支与已支付候选的去重计费。
- 若只解决性能、无新增有效信息，独立报告系统收益和统计风险，不将工程复用夸成新推理理论。

## 7. 与2026文献的差异

- [Conformal Thinking / ICML 2026](https://proceedings.mlr.press/v306/wang26hd.html)：预算风险双阈值已存在。新贡献必须展示风险信号/动作选择/运行时收益，非“加个conformal”。
- [DEER / ICLR 2026](https://proceedings.iclr.cc/paper_files/paper/2026/hash/8df90a1440ce782d1f5607b7a38f2531-Abstract-Conference.html)：trial-answer和PRo式探测已存在；要与完整试答对照。
- [ASAG / ICML 2026](https://proceedings.mlr.press/v306/li26ev.html)：attention-state多动作已存在；不靠扩大动作数声称新颖。
- [REFRAIN / ACL 2026](https://aclanthology.org/2026.acl-long.1256/)：语义冗余和UCB调阈值已存在。
- [SEVRA / 2026预印本](https://arxiv.org/abs/2606.19808)：指出更长的初始预算可能优于昂贵后置验证；我们的29题16k预算结果使固定预算首要。
- [AERA / 2026预印本](https://arxiv.org/abs/2608.27964)：学习未来计算残余价值已被研究（在多候选响应数预算空间）；需说明与单条CoT中候选绑定/廉价读出/长续写的区别。
- [SAGE / ICML 2026](https://proceedings.mlr.press/v306/huang26bn.html)：采样范式影响适当停止行为；与Qwen3官方采样、统一reader等协议相关。
- [Conformal Policy Control / ICML 2026](https://proceedings.mlr.press/v306/prinster26a.html)：不单调有界损失与参考策略安全控制有理论可借鉴；但本项目16k有界FULL并非真实正确/安全oracle，现有有限分层pool也与文献假设不同，不能直接套保证。
