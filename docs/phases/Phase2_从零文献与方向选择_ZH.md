# Phase 2：从零长思维链文献与方向选择

状态：**调研/模块评估完成；作者结果未独立复现；候选新颖性与性能尚未成立。** 更新：2026-11-06；调研截点为2026-11-05。

## 研究问题

从有效长程推理重新出发，理解别人的模块解决什么问题、需要什么信息/计算、何时失败，以及哪些组合能形成可证伪增量；不以旧早停路线或旧性能目标限定新方向。

## 输入与协议

纳入62项研究，区分正式原始来源、预印本、作者效果与本地判断；不把所有条目都称全文精读。文献作用覆盖状态表示、策略、搜索、验证、信用分配、纠错、表示/执行路由和输出。随后新增用户材料与定向近邻核对保留在各自目录，不把新增阅读自动改变原62项口径。

## 实际动作

1. 建立62项文献矩阵、BibTeX/RIS、结构化记录与检索核验日志。
2. 重点阅读29项的方法/实验或关键消融；另33项处于元数据/摘要层。23项具有publisher核验记录。
3. 将算法拆成输入输出、可观察信号、工具/teacher/Gold前提、计算成本和失败机制；评估已有组合与最小消融。
4. 提出纠错承接、关键状态监督、表示路由等候选，优先选择免训练、可同前缀配对的“证伪后状态恢复”短机制诊断。

## 数据与结论

调研QA记录62个唯一引用key、62条BibTeX、62条RIS；保存少量原始元数据与两份用于表格视觉核对的OA PDF，**不是62篇全文下载包**。本阶段新增GPU实验为0。

可保留的研究判断：先挑一个明确失效和两个核心模块，匹配数据、训练/rollout/工具与推理成本；证明新模块超越普通截断、随机干预、重新推导或更多采样。注意力、置信、梯度、压缩率、重复行为等均是代理，不能直接替代最终任务收益或因果必要性。

纠错承接有可检验接口，但TAAR、SCoRe/Satori、DART/TRAE、过程监督及依赖回退等已有近邻；不能把“有反思＋重启/依赖”本身当作新颖性。训练目标与在线可得反馈应分开，Gold/未来轨迹的使用需要明确标注。

## 失败、限制与可证伪猜想

猜想是：一次纠正局部根变量后，后续状态可能没有一致更新，导致派生值复发或错绑；若同输入下的语义干预不优于位置/数量匹配随机干预，或完全重做已解决而局部处理没有成本优势，则不支持复杂恢复模块。

其他候选如稀疏监督、latent/显式路由也可能有价值，但近邻强、训练或接口成本更高。本阶段做优先级判断，不认定文献已证明Qwen上的相同机制，更不按作者最大效果数字承诺本平台收益。

## 下一门槛

该阶段选择的机制诊断已进入[Phase 3](Phase3_P0状态恢复机制与首轮证据_ZH.md)。后续算法仍须：原文/代码身份、无信息泄露控制、真实模型局部效果、失败保留和独立增量；正式benchmark与自然发生率不由调研结论代替。
