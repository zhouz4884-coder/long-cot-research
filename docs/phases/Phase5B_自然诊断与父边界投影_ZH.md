# Phase5-B：自然诊断、建议取舍与父边界投影

2026-11-06。**本轮完成：自然条件诊断、后台DAG切片原型、一次10/10输出的真实组件短试及重数。没有正式自然长链或多数据集质量增益。**

## 在什么目标下，进度到哪里

总目标是提高长思维链最终答案质量，计算成本作为同时报告的维度；不把紧token预算、早停或KV掩码锁定为研究目标。当前子问题是核验范围、修订传播、当前目标与可靠支持如何进入模型执行。

本轮处于**机制筛选/组件可行性**阶段：已知图与精确局部核验条件下能否正确处理E/C/W、保留独立支路、减少重复推导。自动自然图提取、自然核验器、在线逐节点验收/提交、独立确认集、正式多数据集accuracy/pass@1、训练与热KV续接效益均未完成。

单3090/Qwen3-4B/FP16/eager，174.407秒=2.90678单卡分钟；10/10均自然EOS、cap0、unparsed0。768仅保护顶，无尾窗、解析提前停或KV手术。

SharedGFull-E明确采用当前x23/r153，却读旧f275，输出428；当前规则应重算f267、z420。Projection给正确7步，Raw/Restart完整重算也正确。它支持一次可见的旧派生值使用/证书范围问题，不证明内部复制头或KV因果，也不证明超越最强基线。

## 本轮判断与下一门槛

保留父边界作为计算组织模块，尚不作为论文已成立创新。先处理自然诊断显示的目标/答案类型与核验范围：在新的独立自然样本上区分思考错误与交付损失；已审8条不再当独立确认集。若继续版本路线，需同信息G+显式未认证/重算提示、普通DAG切片、长度/文本控制及热cache完整计费，不能只对SharedGFull弱点宣称质量提高。

全部方法本轮fresh-prefill；旧历史作为共同给定输入，未重算其生成成本。62.56%输入减少不能直接推出实际热KV续接总加速。精确全程序解释器本身也能解420，是公开的CPU语义控制，不给LLM算法记功。
