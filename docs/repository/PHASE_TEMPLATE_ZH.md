# Phase N：阶段名称

日期：YYYY-MM-DD。状态：计划 / 进行中 / 范围内完成 / 证据不足 / 冻结。明确区分实测结果与待验证猜想。

## 1. 研究问题与阶段目标

问题、上一阶段证据、当前假说及为什么值得投入。定位变化应说明证据，不预设结果必须符合原机制。

## 2. 输入、对照与冻结协议

模型/分词器/代码/data hash；样本来源与开发/验证/测试角色；primary正确率/成本指标；工具/核验/读出权限；预算、终止与失败分母。

## 4. 数据与结论

## 5. 问题、尝试与猜想

记录问题、尝试、实际效果、未证实解释与下一项能区分原因的检查。负结果不删，副指标不替换未过的主指标。

## 6. 决策与下一门槛
