# 缓存数值等价性：判据修订依据

初版只用 `max_abs_logit <= 0.25`，第二版尝试逐元素 rtol/atol，均因尾部 logits 被判失败。原始失败文件保留 `checks_initial_failure.json` 和 `checks_r2_failure.json`。

独立诊断先测同路径重复，再比较完整/分块前缀，在 BF16 与 FP32 下分别执行。实测同路径重复最大差为 0；FP32 分块差约 4e-5；BF16 差约 0.3–0.5。这个结果支持误差来自浮点计算路径，而不是缓存位置错误。它仍不足以证明任意长轨迹必然完全一致。

用于生成分布的验收改为：所有 logits 的相对 L2 误差 <=1%，概率分布 total variation <=1%，相同 counter-based 随机数下接下来 16 个 token 完全一致。实际 max_abs_logit、top20 误差、TV 都保存，不删除失败。这个判据以 BF16 的相对精度和决策分布为依据，避免由极低概率尾部的绝对误差主导判断。不能只改阈值后宣称原检查通过；修订版必须在真实推理前缀上重新跑完。

研究标签仍来自相同 token IDs 的分支；后续另做相同状态重复采样和长前缀恢复控制，不能把这五个数值检查当作任务性能结果。

后续 BF16 在真实前缀上的相对 L2 达到约 1.2%，仍未满足 1% 判据，未放宽这个判据。改用 FP16 后，最大 logit 差约 0.03–0.05，相对 L2 约 0.08%–0.21%，五组概率/受控生成检查全部通过。主实验由此冻结为 FP16；原版 BF16 greedy 结果作为独立复现，不能作与主方法配对的公平基线。

实际 KV 深拷贝还独立通过：子分支生成不会改变父缓存长度或父 key tensor；两个同状态复制品的受控 continuation 一致。训练采集采用这些实际状态复制品，避免把“完整前缀重放数值接近”等同于“实际分支缓存完全相同”。
