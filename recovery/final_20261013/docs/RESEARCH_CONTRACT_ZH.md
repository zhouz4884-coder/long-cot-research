## 目标与边界

判断继续一个自然推理步骤的准确率净收益是否可测、可预测、可在线利用。STOP/STEP 是输出干预，不证明隐藏层已形成不可逆决策。不预先承诺顶会新颖性、准确率或加速。

## 阶段及验收

1. 原版 24 题预算 0/128/256/512/1024/2048、4096 思考上限、192 答案上限；模型/环境/代码/数据版本与成本留档。
2. 20–30 题 STOP、STEP、FULL；真实模型缓存与完整前缀下一步 logits、受控生成一致性；自然与强制结束格式对照；Math-Verify 与人工抽检。先通过正确性，再训练。
3. 150 题开发集，自然与反思检查点并存，保留所有超限和解析失败；动作先取 STOP/一步/FULL，必要时扩展多步。
4. 分别预测 beneficial fix 与 harmful flip；5-fold GroupKFold，所有轨迹/检查点按题目隔离；长度/单置信度/熵/随机对照；稀有事件只在训练重采样。
5. 冻结训练器和工程集阈值后，独立在线决策；不能把离线选答案称为在线加速。记录答案 token、思考 token、prefill、决策、GPU 和 wall-clock 成本。
6. 问题聚类 bootstrap、同输入/重复采样控制、失败归因、第二模型小规模验证；输出 GO/NO-GO/继续诊断。

## 在线可获得性

检查点只依据已经生成的 token；不回到未来出现反思词之前。自然检查点为完整段落/步骤边界；反思词被观察后才可触发。150 token 为软预算，额外 grace window；硬超限作为事件保存，不能剔除。廉价特征只来自已有 logits、长度、历史反思频次、重复率和步骤。Attention 探针单独计费。

配对分支保存 problem_id、trace_id、checkpoint_id、prefix token IDs/hash、model revision、seed、动作、正确性、解析状态、真实成本、length_censored。分支的离线重放成本与在线控制器成本分别报告。用部分相同状态重复采样衡量温度噪声；单个随机翻转不等于确定性因果效应。

## 判断

先排除缓存、截断、评分与泄漏错误；再判断未见题目上净收益预测是否超过简单特征；最后检验质量约束下 Token 与真实耗时 Pareto 是否超过 EAT 和一项可复现强基线。15–20% token 节省只是积极信号。300 题未必足以证明 <1pp 非劣；置信区间不足时报告继续诊断。不得因缺少预算、时间或基线而写虚假 GO。

Agent 工具调度为第一备选；需要真实资源瓶颈证据，普通 CPU/I/O 工具不强行分配 V100。此轮不擅自转向其他研究主线。
