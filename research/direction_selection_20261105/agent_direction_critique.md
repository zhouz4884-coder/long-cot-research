# 三个组合方向的独立审查

审查日期：2026-11-05。范围：核对用户建议、两份背景 PDF 的页级提取、VCORE 与 STOP 原文及表格，并对关键近邻做官方来源复查。本轮仅提出选择与实验门槛，没有连接服务器、修改实验代码或运行 GPU 实验。2×3090 按用户现有资源规划；V100 数量、显存、排队及运行库适配均未实测，不计入首轮预算。

## 我的选择

**优先做方向二的一个收缩版本：证伪事件后的状态重建是否比继续追加纠错文本更有价值。** 暂用研究问题名“纠错后状态重建”，先不把它命名为一种已经有效的 KV 手术算法。首轮只回答：在同一个纠错检查点，明确定位的错误分支被移除并重新计算状态后，是否真的更少复发、更容易答对；以及直接删 KV 与重建后的状态是否等价。

优先级是 **二 > 一 > 三**，这是“以有限预算尽快否证关键前提”的排序，不是录用概率或潜在最终收益排序。

| 方向 | 可以立即检验的实质问题 | 当前最关键的未证前提 | 当前决策 |
|---|---|---|---|
| 二：证伪分支与状态恢复 | 改口之后，删除失效内容并重建状态是否优于追加同一纠错信息 | 有足够多可观察的自然复发；修复收益能超过随机压缩和重算成本 | 首选一个带 oracle 边界的机制筛查；原版“直接物理删掉就净化”不成立为先验 |
| 一：阶段解耦与锚点梯度 | 后置片段是否改变参考梯度，使真实可迁移推理训练受损 | token 占比会形成有害梯度；答案梯度比全链梯度更利于独立解题 | 第二顺位；先测梯度假设，成立后才微调 |
| 三：主动压力测试后退出 | 一次质疑相对同预算自然续写是否更会识别未来可纠正的错答 | steering 能产生有效检验；检验后的不变信念能校准风险 | 第三顺位；先测主动诊断的信息增量，再谈向量与早停 |

选择二的原因是它可以先用明确的状态干预与合法上界排除错误机制，无需先训练一个可能无效的模型。代价是它与依赖回退、缓存重建已有显著近邻；若只得到“删错历史有用”，贡献会很薄。后续必须证明可观测触发器、状态恢复方式与真实净成本之间有可复现的增量。

## 原建议中的事实、推断和错误

### 方向一：VCORE × STOP

**已核事实。** VCORE 的效用是 token 梯度与总体训练损失梯度的内积；实现用独立参考 batch 的均匀监督梯度估计该方向，推导属于小步 SGD 的一阶损失下降近似（原文 PDF 第 4 页，式 2）。其目标是下降既定训练分布上的损失。把参考损失换成结论/答案损失，等于改变目标，不是修正同一目标下已被证明的估计偏差。[VCORE 原文](https://aclanthology.org/2026.acl-long.1298.pdf)

**未被证明的核心假说。** “后置废话污染全局梯度”值得测，但不能从后置 token 占比直接推出。容易预测的模板可以占很多 token 却产生很小梯度；验证行为也可能提供跨题可迁移训练信号。STOP 的输出长度变化、Reasoning Theater 的信念读出结果，不能替代在 VCORE 使用的同一训练语料、同一模型、同一 checkpoint 上的梯度测量。VCORE 在 GSM8K 上的退化和部分 OOD 上低于 DFT，只能说明这些设置存在退化，不能识别其成因为 post-ECN 片段。

**关键定义不能简化。** STOP 的规则只负责节点切分；ECN 还要求节点是回答本题的结论、且答案正确。原文对隐式/含糊结论使用带题目和 gold 的标注模型判断。正文使用 DeepSeek-V4-Flash，另用 Gemini-2.5-Flash 复核。数字第一次出现、第一次字符串匹配或一次短试答，都不是该定义的等价实现。它也不是“推理已经完成”的真值，只是某条已知正确轨迹中的一个训练剪枝边界。[STOP 原文 §2.2–2.3](https://aclanthology.org/2026.findings-emnlp.672.pdf)

**表格与归因应修正。** STOP 表 1 中，Qwen AIME 的 SD-Full / SD-ECN 是 53.3% / 46.7%，Llama 是 60.0% / 40.0%。但 Llama GSM8K 是 82.2% / 83.2%，MATH500 是 82.2% / 87.7%；ECN 并非在 Llama 各任务都低于 SD-Full。AIME 小样本差异不能自行解释为“丧失验算习惯”，也不能推出加一个节点就能恢复。上述表格已对原 PDF 页图目视核对。

**“因果”命名过早。** 内积测的是所选参数化、所选 checkpoint 与所选教师强制条件下的局部优化相容性，不直接证明某个 token 对答案的因果必要性。若锚点答案损失仍以完整金标准推理前缀为条件，它还可能奖励数字/格式复制，而非独立求解；独立参考 batch 不能消除这种目标错位。AdamW 与实际多步训练也不自动继承 SGD 小步推导。

**硬件与工时不是事实。** VCORE 正文训练配置是四张 RTX PRO 6000 Blackwell、batch 32、一轮 LoRA；Qwen 用 r=8，Llama 用 r=64。STOP 使用单张 A100 80GB、最长 8192。由样本数/batch 推出约 100 步，不能推出 2×3090 在两小时内完成同配置训练；扰动前向、参考 batch、checkpointing 与长序列激活都要计时、测峰值显存。

**最近邻。** [LESS，ICML 2024](https://proceedings.mlr.press/v235/xia24c.html) 已经通过目标示例与训练示例的低秩梯度相似性选择训练数据；[GRAIL，2026 预印本](https://arxiv.org/abs/2606.04889) 已用对最终答案敏感的梯度-激活 saliency 做 token 级 advantage 重加权。两者不等价于此提议，但“目标/答案锚点 + 梯度 + 重加权”不是空白。可成立的差异需要落到：阶段混杂是否可测、哪个参考目标能稳定改善独立解题、相比简单阶段删减与答案加权有什么额外收益。

**若下一轮轮到方向一。** 先用同一模型和同一批轨迹，比较全链、ECN 前缀、答案锚点、随机等 token 数锚点四种参考梯度。用独立题的实际小步更新和自由生成准确率验证，不能只看更低的教师强制答案 loss。只有锚点优于简单去尾、随机锚点和 DFT，才值得进入完整微调；P0 不同时加入“一节点缓冲”和新方差缩放，以免无法归因。

### 方向二：证伪分支 KV 操作

**机制上确定的部分。** 在通常的稠密因果 Transformer 中，某个后继 token 的高层 KV 已通过前层表示吸收其可见前缀信息。事后删除早期错误 token 的 KV，只阻断未来对这些行的直接访问；它不会追溯重算已经生成的后继 KV。文字上看似独立、没有变量名交集，也不是计算图独立。保留一个纠错节点的旧 KV，还可能保留它读过错误分支的表示。

因此，“删掉错误行而保留后继”等于“得到干净前缀状态”没有一般保证。若要把二者相等当作优化，应先与同一保留文本、同一位置设置的冷 prefill 比较。若位置重编号，RoPE 相对位置与后继 token 的位置都会改变；若保留原始位置的空洞，则要明确 cache_position、position_ids、mask 和下一 token 位置。不能把这些差异当成语义净化效果。

**墓碑不是原缓存中现成的二十个 token。** 新写的摘要需要实际 tokenization、forward/prefill；它必须由检查点前已观察到的信息构造，不能把 gold 正确答案或后续才发现的依赖偷偷写进去。纠错句本身也可能错。“Wait/Wrong”只能产生候选事件，不能自动证明一个分支被证伪。

**仍待实测的部分。** 自然纠错后的旧值复发是否足够常见；是否由对错误分支的直接注意力引起；语义删除是否优于随机删除；保留反例摘要是否防止重复探索。注意力高不代表错误信息造成最终错误，也不意味着 R-KV 一定比随机策略更爱保留错误式子。[R-KV](https://arxiv.org/abs/2505.24133) 还使用冗余信息，不能概括成只按单一注意力分数排序。

**最近邻与必须加入的控制。** [TAAR，Findings ACL 2026](https://aclanthology.org/2026.findings-acl.1930/) 已用诊断策略选陷阱位置并回退重启，其“基础模型不微调”不等于完整系统没有训练；可选 reboot suffix 也使“完全失忆”这一批评过强。[Dependency-guided Rollback Repair](https://arxiv.org/abs/2608.10502) 已做错误依赖撤回、保留独立支持、选择性重放，但对象是持久 memory agent。[Budgeted Cache Repair](https://arxiv.org/abs/2610.02233) 已研究改变前缀后的缓存误差和预算化重算，但目标是跨上下文复用。[Random Attention](https://arxiv.org/abs/2609.03430) 提醒保护 prompt 的随机淘汰本身可能很强，故同保留量随机控制是必需的。顺带纠正：LongFlow 官方版本是 [EMNLP 2026](https://aclanthology.org/2026.emnlp-main.112/)，不是输入背景中写的 ACL 2026。

可辩护的新问题是：**自然单链已发生可观察证伪时，错误依赖与缓存陈旧分别贡献多少复发风险；修复能否在相同有效预算下胜过完整回退、追加纠错与随机压缩。** 当前没有数据支持“一石三鸟”。

### 方向三：单步压力测试与早停

**已核事实与范围。** [Stable Answers, Unfinished Reasoning](https://arxiv.org/abs/2609.09989) 报告所测 3520 种一致性规则未过预声明门槛，且同流程中的 DEER 置信度控制通过。不能将它解释成所有探针早停失败，也不是所有主动检验有效的证据。其“后续放弃该答案”与最终答错不是相同事件，应分开计数。

**关键逻辑缺口。** 单次定向扰动后答案不变，只能说明在那一种、那一强度、那一次干预下未改变答案。可能是检验未覆盖漏掉的约束、模型不具备反例生成能力、steering 没有生效，或者答案读出器不敏感。激活漂移幅度也不是推理完成度。即使生成了正确的局部边界检查，也不保证所有关键分支被覆盖。把此结果叫“真收敛”或“立即安全早停”都过强。

**最近邻。** [CREST](https://arxiv.org/abs/2512.24574) 的离线认知头校准与推理时旋转/抑制，不能直接当成已存在的“只激发有效反例验证”的通用向量；还需证明所提方向确实诱发有效验证。DEER、Reasoning Theater、[Conformal Thinking](https://proceedings.mlr.press/v306/wang26hd.html) 分别覆盖置信、信念读出与统计风险校准，不能只和两次答案一致性比较。

**若下一轮轮到方向三。** 在冻结的候选退出点，先比较普通文字质疑、同 token 预算自然续写、随机/反向向量与目标向量，对“未来本会纠正的错答”的检测增量。若普通文字质疑已经相同或更好，先采用它；若所有主动分支都不优于等预算续写，就停止 steering 路线。任何后续退出策略都要在独立校准集锁定阈值，在留出集报告有害提交、修复机会被截断、覆盖率及全成本，不由一个不变答案推出安全。

## 当前 P0 与后续可选 P1

当前 P0 先完成 CPU 接口/缓存一致性诊断，GPU 仅作为通过接口控制后的极小试错选项（目标 0.5 GPU 小时，硬上限 1 GPU 小时）。下面的自然纠错事件六臂设计是**后续可选 P1**，不作为当前首轮工作或预算承诺。

### 后续可选 P1：三步

### 1. 冻结事件与建立可比较状态

先检查已有轨迹中能否取得 24 个自然纠错检查点：采样问题在看结果前固定；每题最多一个检查点；事件应有明确被否定的旧断言，以及检查点前已经表达的矛盾或撤回。人工/可执行检查器只用于离线标记错误分支与依赖，不在在线方法中读取 gold。不能按后续是否复发筛选样本。按 problem ID 划分 12 个开发、12 个审计；另设 8 个“纠错仍然错误、只说 Wait 但未撤回、没有错误”的负控制。样本少，目的只是强信号筛查，不是最终风险认证。

若现有轨迹不足，只允许在预先冻结的最多 64 道问题上采一次原始轨迹，每条上限 8192；观察纠错发生率、合格事件数与后续复发率。预算内仍收不到 24 个事件，记录这一适用面结果，停止自然事件算法化，不用人工注错样本冒充自然复发率。可用少量带精确解的注错题检查实现，但单独报告。

在 8 个同输入样本上，先验证“无修改续写”与同文本重新 prefill 的 logit/答案差异，并重复运行建立数值噪声范围。固定模型权重、tokenizer、dtype、backend、采样参数、种子与最大生成预算。若无修改控制已有显著漂移，先排查实现或数值原因；在它稳定前不归因给语义修改。

### 2. 在每个事件做成对干预

所有摘要只复述检查点前已有的否定结论，内容固定，禁止额外提供正确答案；每个分支最多继续 1024 token，固定两组种子，逐题配对。比较以下分支，首轮不训练触发器，不做向量学习：

| 分支 | 操作 | 回答的问题 |
|---|---|---|
| A | 原状态继续 | 基线实际会发生什么 |
| B | 完整上下文追加固定否定摘要 | 仅强调纠错信息是否已经足够 |
| C | 按离线 oracle 标记删除失效分支，追加同一摘要，冷 prefill | 语义移除和干净状态的上界是否有价值 |
| D | 保护 prompt/纠错结论，以相同 token 数随机删除并冷 prefill，追加同一摘要 | 收益是否只是缩短、扰动或一般压缩 |
| E | 在旧缓存中只删除 C 对应的 KV 行，再实际前向写入同一摘要 | 直接删 KV 是否足以接近 C |
| F | 回退到错误假设前，追加同一摘要，再冷 prefill | 是否优于更简单的回退重启 |

C 与 E 必须使用相同保留文本、相同原始 position_ids、相同下一位置和 mask 语义，避免把 RoPE 重编号混入陈旧缓存差异。若实现无法可靠保留空洞位置，先完成 A/B/C/D/F 的文本级上界，只能报告状态重建结果；E 未完成不影响否证“删历史本身有没有用”，但不能形成 KV 手术结论。所有完整 prefill、摘要前向、检测/标注成本、被丢弃生成和失败重试都分别计入成本账。

### 3. 用预声明门槛决定继续、收缩或停止

主指标是最终答案成对正确性变化；次指标是“已被否定且在检查点前明确归属错误分支的断言，后来被重新当作有效前提使用”的复发。单纯重提旧数值、引用反例或文字相似不算复发。再报告破坏原本正确续写的次数、生成 token、prefill token、端到端时间、峰值显存与事件发生率。审计集结果按问题聚合，两 seed 不是两倍独立题数。

这是一个小样本强信号启动门槛：开发与审计、两个 seed 的净正确题差方向都一致，且审计集中 C 相对 B 与 D 至少各净多修复 2/12 题，才支持进入扩大样本阶段；这个较高门槛是控制试错成本的工程选择，不是显著性声明。须同时给出全部成对结果与按问题计算的区间，不把通过 P0 当作准确率保证。若差异不足或区间很宽，结论是“现预算下不够支持扩展”，不调参到过线。

- **C 不优于 B：停止语义删段主张。** 猜想是纠错强调已足够、保留信息有用、复发主要由模型能力而非可见历史造成。后续只值得检查少量例子的标签与因果定位，不能直接追加更多模块。
- **C 与 D 相当：停止“证伪特异性”主张。** 猜想是一般压缩、距离或干预噪声在起作用；转而按缓存压缩路线比较，不包装成逻辑修复。
- **C 有效、E 无效：拒绝纯 KV 删除实现，保留重建研究。** 猜想是受影响后继缓存、mask/位置错误或数值放大；先用同文本同位置冷 prefill 判定，再做恢复范围消融。该结果本身不能证明自然样本均有广泛状态污染。
- **C 有效但不优于 F，或全成本更差：冻结外科手术效率主张。** 简单回退是当前更合适方案；只有可观测在线依赖能减少重算并保住质量，才继续做局部重建。
- **只在注错题有效、自然事件无效：收缩到受控现象。** 不声称解决真实长 CoT 纠错；解释可能是注错强度/文本形式造成分布差异，或真实纠错本就稀少。
- **oracle-C 有效而可观测触发器失败：定位为诊断瓶颈。** 不用 oracle 实验的增益冒充在线系统收益。下一轮最多研究检测质量，不同时优化缓存内核。

## 硬预算与交付

**当前 P0 初轮先做接口与 CPU 数值诊断；GPU 试错目标累计 0.5 GPU 小时，硬上限累计 1 GPU 小时，预算到即停。** 不训练、不租卡、不依赖 V100，也不承诺固定墙钟完成时间。CPU 缓存一致性控制只验证状态机制，不代替训练模型的自然纠错证据。前述自然事件六臂方案属于 CPU 控制通过后的可选 P1：若后续决定扩大，才采用两张现有 3090 累计 12 GPU 小时、100 万实际新增生成 token 任一先到即停的 P1 上限；它不是当前首轮授权预算。原轨迹生成、各干预续写及重试一起占生成 token/GPU 预算；prefill 单独记录并计入 GPU 小时和端到端成本。模型先选一个已验证可运行的 4B–8B 骨干并测长序列峰值显存；若需缩小模型，必须声明外推边界。

需要保留：冻结问题清单与切分、每个检查点前缀、oracle 标注与可观测信息边界、所有分支文本、原始预测与成对正确性、位置/mask/cache 配置、软件/权重 hash、逐请求成本。P0/P1 均可以交付明确 NO-GO；不能交付未经自然留出验证的算法胜利、原创性认证或会议承诺。
