# 检索、核验与证据边界

日期：2026-11-05。用户明确要求从零调研长思维链，理解思想/模块/效果及可组合点。本轮未使用旧早停实验作为选题依据，未恢复旧GPU队列，未创建持续目标或定时任务。

## 流程和来源

使用nature-academic-search的多源发现、引用核对和参考文献管理流程。学术MCP专用检索工具在当前会话未挂载；实际使用互联网检索定位原始记录，并打开arXiv、PMLR、会议正式页面、ACL Anthology、作者研究页及Crossref DOI元数据。没有声称使用过Scopus/Web of Science或系统性追完所有被引。

本轮是范围型/叙述型调研，不是预注册系统综述。纳入62项是经核对的最终库规模；搜索引擎返回不提供稳定筛选总体数，因此不编造PRISMA式“总检出/总排除”数量。

检索主题覆盖：Long CoT、reasoning SFT/RLVR、test-time scaling、process supervision、self-correction、thought search、credit assignment、reasoning graph、latent/hybrid reasoning、faithfulness、overthinking、causal intervention、dependency rollback，以及视觉/音频邻近表示。

示例实际检索式：

- long chain of thought / reasoning / training / mechanisms / 2025 / 2026
- reinforcement learning beyond base model / pass@k / reasoning capacity
- long chain-of-thought / credit assignment / Echo Trap
- latent reasoning / explicit verification / hybrid / 2026
- reasoning / counterfactual / critical steps
- reasoning / rollback / dependency
- 各核心论文的完整标题，配合arxiv.org、openreview.net、proceedings.mlr.press、proceedings.neurips.cc、aclanthology.org、nature.com等来源限制

第一轮按谱系和主题扩展；第二轮围绕模块失效与组合补检，找到LaTER、HRPO、Pre2、CRV、RELIEF、DeepRewind、Logic Tree等直接近邻，缩小了可声称的新颖性范围。没有把一般新闻、社交帖子、个人总结作为效果证据。

## 最终文献库

- 62项唯一标题/主要记录；去重时将同一工作arXiv和正式会议版本合并。
- 23项直接核对出版方/DOI记录，39项以arXiv条目为引用；后者中会议接收备注单独记录，未将under review当录用。
- 29项重点阅读方法/实验或关键消融，33项为元数据/摘要级核查。A层不等同全篇逐字/证明复核，亦不等同代码复现。
- RIS和BibTeX保留各自的可核对来源；DeepSeek-R1使用Nature/Crossref正式题名与作者，另保留技术报告链接用于方法和表格核对。
- 基础CoT、agent恢复、多模态工作均明确标注与现代单模型长链的对象差别。

## 数字核对规则

每个效果带有模型、任务或原始设置的必要限定。未得到一个明确、可追踪数字时，保留定性效果，不填猜测的统一“提升率”。区分百分点与相对百分比，pass@1与pass@k，跨基准平均与单基准，token/latent步/模型调用/FLOPs/真实时间。

按表格优先核对了VCORE和STOP的两张表，使用官方OA PDF、校验PDF签名、以PyMuPDF本地渲染实际查看；它们位于sources/。其余重点方法通过原始HTML或web PDF选择性阅读，来源链接和章节在阅读札记中给出。

发现的边界/问题：

1. 最初记忆中的TokenSkip arXiv ID 2502.12014实际是Ising–Potts论文，已排除；最终使用正式EMNLP2025条目及出版方BibTeX。
2. 某些OpenReview链接触发浏览器校验，停止该路径；Nature HTML也出现不可访问的认证重定向。采用独立合法OA/arXiv记录或不纳入，不绕过挑战、不索取凭据。
3. STOP正文对两个模型都改善的概括与表1的Llama GSM8K下降不完全一致；引用原表，不强行统一。部分跨页正文数字也与原表不一致，正式复现前应核对更正。
4. VCORE的宏平均最好不能改写为每个骨干/每个OOD都最好；DART不同骨干的pass@1/pass@8也有取舍。
5. ReST-MCTS*的某些逐基准结果并不随迭代单调提升；对有疑义的平均列不拿来做核心效果数字。
6. 行为蒸馏表2是训练集诊断，不作为独立泛化数字；其经验结论不意味着事实正确性可被普遍忽略。
7. SPAE的Gold似然是训练期信号；“探针不训练”不等于整个算法免训练，更不等于部署能用Gold。

## 复核与交付

最终检查条目数、唯一citation key、作者/题名/年份/来源完整性、RIS结尾、BibTeX括号、报告中的文献编号和本地链接。下载manifest记录两份OA PDF及出版方元数据的URL、字节和SHA；只读源文件不修改。

本轮没有进行独立性能复现，也未证明任何候选创新是首次。下一步若收敛到一个问题，应对该问题做更窄的引文追踪、代码/设置核对与小规模证伪。文献搜索没有发现某种组合，不能独立证明它不存在。
