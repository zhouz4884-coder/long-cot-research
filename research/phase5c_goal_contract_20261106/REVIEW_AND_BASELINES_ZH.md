# Phase5-C建议审查：目标契约、冲突核验与终局投影

2026-11-06。只读完整审查新附件、Phase5-B原始结论及自然诊断；新增GPU为0，旧源码/原始结果/分数未改。本文是设计审查，不预填自然质量收益。

## 判断：方向可试，尚不能“方法定型”

采纳把实验转向真实长轨迹的目标/答案类型与终局交付；采纳先单模型、足够独立题目，再扩模型/数据集。Phase5-B只有1个程序，其三态投影prompt相同，确实不足以验证泛化。多模型、多数据集与方法基线是三个不同维度，最终都需要；当前先补独立样本数和强对照。

旧8题已用于诊断/构思，只能留作开发病例。下一轮应排除旧冻结100题，从剩余200条历史FULL轨迹按预声明ID哈希及可见cap/词法修订特征抽取24或32个独立problem_id；不按答错/Gold/候选是否正确挑题。若富集cap/修订，必须报告条件样本，不能当完整MATH500准确率。32题也只是探索轮，报告配对修复/伤害与不确定性，不凭一个点估计宣称普遍增益。

## 附件中必须纠正的事实与推断

| 建议或说法 | 本次判断 |
|---|---|
| 自然E-Reuse为0/8，所以现代模型自然生成都会替换正确 | 不成立。8条是按历史答错筛出的条件子集，不能推出自然E不存在或浅层修订必然正确；9条cap只看窗口，其他正确轨迹多数未读。 |
| 其余5题占非建模错误100%，已经证明两大病灶 | 是事后重分组、部分标签重叠的诊断描述，不是总体发生率。Rank32只见公式反复/未完成，不能直接计confirmed W；39有明确正确到错误前缀，88有错误复核与未解决冲突。 |
| Rank62目标是复根模长和或所有根模长和 | 写错目标。原题要5个共轭对的\(\sum_{i=1}^{5}1/(r_i\bar r_i)\)，不是\(\sum |z_i|\)。其值850。目标契约若抄错这一点，方法会精准解错题。 |
| Rank88用x=1就能证明余式为0 | 不成立。令f=x³−3x²+4x−1，g=x⁹+6x⁶+31x³−1；f(1)=1、g(1)=37。独立CPU核得rem(g,f)=0，但g+(x−1)在x=1同值，余式却为x−1。单点可证伪部分恒等式，不能认证恒等/可整除。应精确多项式余式/全系数检查；随机点检若用则明示概率与误差界。 |
| SharedGFull错误由“强调153诱发检索275”导致 | 与输出兼容，但只是猜想；该输入未做独立重复、文本位置或因果控制，不能作已证机制。 |
| 黑名单禁止父节点数字成为答案 | 不采用数值黑名单。中间量可能恰等于最终目标；应检查目标身份、作用域、关系、单位与答案对象。概率0、1或0.33不因未写p/q而无效。 |
| 型别检查足以证明答对 | 只检查对象完整性。三元组型别正确仍可能数值错误；单实数也可能不是所求。 |
| 老候选有完整推导，后修订必须过G | 修改后采纳。旧候选自身也须有适用证据，不能无条件偏爱早答案；证据不足保留unknown/多候选。另一次同模型判断不是独立真值证书。 |
| 正确父边界从T抽出后可压到<300token并保证救回 | 尚待实现和测试。不得按Gold/人工正解节点选边界；未知依赖不静默删除，错误/不全的边界可能丢关键条件。原题本身可能已超过300token。 |

本表的两项数学纠偏由可见原题与本地SymPy精确计算核对；没有用Gold选择模型输入或重评分旧run。

## 当前小轮应保留的比较

建议主比较使用相同P、同一条固定历史T、同模型/采样与预声明新增计算预算。所有输出按同一新分数/表达式/元组契约评分，不用“首个闭合brace”截断合法对象。

| 条件 | 作用 |
|---|---|
| FullHistory：完整T＋普通自然终局续写 | 强质量基线，不能只赢已知有读出问题的boxed提示。 |
| FullHistory＋K：目标/答案类型契约，保持完整T | 判断仅重复目标和交付对象是否已经足够。 |
| FullHistory＋K＋同候选/G证据 | 与Ours同核验信息/工具的组件对照，判断投影的新增价值；不能把独占正确支持算作投影收益。 |
| Projected＋K，不启用G | 使用同一无Gold提取器、保留其未认证状态，判断G是否必要。 |
| Projected＋K＋G（候选Ours） | 只有真实实现了候选、范围核验与fallback才用完整名称；尚无G则明确叫候选投影。 |

辅助控制：历史ForcedCue是协议兼容/读出故障对照，不能叫原始作者行为精确复现，也不能自动将旧失败复现为成功条件；RestartP是从题干重算的强简单控制，可检验复杂救援是否必要。若算力只允许较少臂，至少保留FullHistory、FullHistory＋K、同G全历史、Projected＋K＋G；将缺少无G投影消融记为未完成，不能归因三模块各不可替代。

若廉价固定窗口/最近候选摘要已相当有效，应追加为同成本简单基线，不把任何截短效果归给“父边界”。若两种方案实际产生相同prompt，记录等价，不作为两个独立算法成绩。

## 准入、计费和结论范围

- K只能从P提取；候选/边界只能从可见T提取，保留原始span及未认证/冲突状态。不能人工挑正确候选或用原8题特例模板冒充自然自动算法。
- G应列支持的规则/核验范围及unknown率。局部等式正确不等于原题建模正确；工具已能算全题时保留同工具普通执行器对照。
- 预算256若使用，称为“固定轨迹后的新增终局预算”。Ours若另有候选提取/核验LLM调用，其生成必须计入总新增预算；prefill、工具、重编码、失败/拒绝另计。不要只把最后答案那一调用与单调用基线比。
- 固定T的读出/救援结果不是自然端到端RawFull准确率。历史T带8192思考保护和forced readout来源；所有新臂应按同一新协议重新测，旧历史grade只作诊断参考。
- 新一轮不是证明“8000token垃圾注意力分散”因果机制。报告最终正确率、EOS/cap/解析、paired repairs/harms、输入/输出与全成本。若只在紧终局预算下有效，定位预算内交付效应；不声称无预算质量上限提高。
- 预留后续独立确认集。若先看8题后修改方法，这8题成为开发集，后24题仍须按新冻结协议执行；不能合并报告成未经调参的32题确认结果。

当前无外部阻塞，但存在科学准入条件：自动K/候选/G的定义与支持范围尚须具体实现并冻结，不能以报告中的人工正确边界直接进入自然效果主表。
