## 冻结与调用

评分只读已生成的 `final_response`，并要求 `EOS is True` 与 `think_closed is True`。题目在运行前公开的 `answer_kind` 参与解释对象类型。D3 AIME 与 Olympiad 小试使用冻结可见清单中的 `scalar`。历史 rank 88 的答案为有序三元组，开发复核使用 `tuple`。

```python
from complete_answer import backend_status, score_final_answer

assert backend_status()["status"] == "ok"
scored = score_final_answer(
    raw["final_response"],
    gold,
    answer_kind=visible_case["answer_kind"],
    eos=raw["EOS"],
    think_closed=raw["think_closed"],
)
```

`extract_final_answer` 仅接收答复和公开题型，输出源字符跨度、答复哈希、对象类型、组件和单位。`grade_final_answer` 在对象选定后读取标准答案。`score_final_answer` 返回独立的 `selection` 和 `grade`。冻结评分源码、测试、开发回放和运行时版本见 `COMPLETE_ANSWER_FREEZE.json`。使用新题标准答案前，调用方应验证生成已冻结、评分源码哈希和后端版本。

## 读出与比较

| 对象 | 处理 |
| --- | --- |
| 标量、分数、根式 | 读出完整对象。能转成有理数时使用精确有理数比较，其他组件由固定版本 LaTeX 解析器读取全输入。 |
| 解集 | 显式集合括号、明确的解集措辞或预冻结集合题型可为并列装框赋予集合类型。支持逗号、`\quad` 与明确连接词。集合成员按数学等价去重并无序匹配。 |
| 多重集 | 使用预冻结的 `multiset` 类型，无序匹配并保留重复次数。 |
| 有序元组、向量 | 保留组件顺序。向量允许坐标形式和行列环境，两边均显式提供行列形状时核对形状。 |
| 区间 | 核对端点顺序与开闭。没有题型依据的两元素圆括号对象保留歧义。 |
| 文字单位 | 识别有限词表中的合法后缀与常用平方、立方形式。标准答案显式给出物理单位时核对规范化单位。只给数值的标准答案以数值为评分对象。人数等计数标签允许省略。 |
| 备选、重复和未完成 | 对冲突结论、缺少类型的并列对象和未闭合结构保留歧义或不完整状态。对显式重复，依据同一规范表面或精确有理数等价合并。出现 `or` 时，只有明确的解集语境或集合括号可将其作为同一解集的连接词。 |

明确的最终答案段和终端数学对象提供读出边界。中间装框后仍在推导、最终段内有竞争对象、或终端装框被任意额外正文包裹时，保留无法交付状态。整对象数学解析避免对残缺或混杂表面退化成读取最后一个数字。评分进程使用冻结的 Math-Verify 0.9.0 与 latex2sympy2_extended 1.11.0，有单案 20 秒 CPU 子进程期限。标准答案数学解析失败、候选数学解析失败与未交付分别留痕。

## 开发复核

D2 原 LastBox 在逗号相连的四个框上弃权，在 `\quad` 间隔的另一种子上只取最后一个根。新版在这两份原始答复中均选出四根并通过独立数学评分。测试也包含有序三元组丢失分量、顺序错配、集合重复、不同区间开闭、单位不符、先给一个数再用另一个数装框等反向控制。

首次 48 条旧轨迹回放为 44 条通过、2 条未交付和 2 条标准答案解析未知。追查发现，含“students”的计数标准答案需要明确词表，含明确结论引导语的终端装框需要与步骤标题区分。加入通用规则并补充反例后，回放为 **47/48**，21 项 CPU 测试及其中 29 个数学和类型子例通过。唯一未交付的 D2_05 在同一结论句中用框写本金，单位后还有本金用途、未来金额和利率。该句超出当前终端对象与单位语法。

D2 历史冻结分数为 **46/48**，独立数学内容复核为 **48/48**。本次旧数据回放是开发诊断，保留首次与修正两份回放。此版本限于受支持的浅层数学对象、已登记单位及保守的终端语法，任意自然语言单位换算、嵌套数学对象和结论中的自由文本解释仍可能弃权。
