# D3 正式批评分读出 v2

标定批的 v1 冻结分数为 **4/8**。P01 和 P04 在明确的最终答案段末尾，用一条等式链交付一个装框标量。v1 把框前的等式当作额外内容并弃权。两条原文分别为 `p + q = 657 + 64 = \boxed{721}` 和 `a + b + c = 3 + 57 + 2 = \boxed{62}`。

v2 先运行 v1，仅在原结果因装框未独占最终段而弃权时检查一种更窄的交付形式。答复必须有单一明确的最终答案锚点，终端显示公式必须以唯一的装框标量结束。检查器用精确有理数重算等式链的各项。首项若含符号，仅使用同一最终段中带原文跨度的显式、无冲突、闭合赋值，并要求它之后至少有一个可独立计算的闭合项。假设性赋值、未绑定符号、近似关系、竞争答案、附加后缀和超限表达式仍沿用 v1 结果。证明范围是所写局部等式的一致性，整道题的正确性仍由选定对象与标准答案比较。

正式评分调用 `complete_answer_v2.score_final_answer`，传入可见题型、原始最终答复和实际终止状态。调用方应在打开正式标准答案前核对 `COMPLETE_ANSWER_V2_FREEZE.json` 所绑定的 v1、v2 源码哈希及评分后端。原 v1 的对象比较、分数和标定生成记录保持冻结。

30 项 CPU 测试通过。使用已关闭标定批的同一组八份原始答复，本地复现 v1 **4/8**，v2 事后回放 **6/8**。只有 P01 和 P04 的读出发生变化，其余六条的提取及评分完全一致。该差异计入评分规则开发记录。正式实验中的推理收益须在同一冻结 v2 规则下比较各实验臂。
