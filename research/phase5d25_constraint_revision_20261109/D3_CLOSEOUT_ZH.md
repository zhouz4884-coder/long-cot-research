# D2.5 与 D3 收尾报告

## 结论

D2.5 完成了作用域、类型核验、独立审计及最终答案读出改造。实机旁路对照在四个冻结检查点均复现原生续推。一个历史多项式错例中，三条开发臂均答对，承接臂比普通回退少用 36.1% 的时间。

D3 的 16 道新题以两个种子完成了 32 条正式轨迹，全部自然 EOS。原生冻结成绩为 **16/32**。自然作用域配对准入 **0**。这一轮证实题集有最终答案错误空间，同时定位到当前方法的自然证据覆盖瓶颈。**正式配对准确率增量与等成本修复效果不可估计。** [评分](bank/SCORES.json) · [配对准入](quality/D3_PAIR_SELECTION.json)

## 1. D2.5 改造与复测

重新按字节哈希复核 222 个旧原始文件，重现 48 条自然轨迹、460 条关系、162 条符号作用域缺失和 12 条无反例变量的 UNKNOWN。旧核查臂共享相同提示和采样路径，四题耗时的 27.2% 差异混合了提示改动与实际核查成本。

新符号环境区分原题前提、局部定义、临时假设、同名遮蔽和变量版本。原 162 条缺 scope 的关系中，42 条取得条件作用域，0 条获得完整原题权限。同批关系按形式恒等核验口径得到 14 条形式证书，均未授权修订。近似、精确等式和累计表达式分开处理。五条舍入、四条续加及相应反向控制在 CPU 通过。复跑还修正了把阶乘符号当标点、把 Markdown 列表标记当负号的问题。对不完整的表面仍保留 UNKNOWN。[继承审计](INHERITED_D2_AUDIT.json) · [范围逐条复算](diagnostics/d2_v2/ORIGINAL_162_RECOUNT.json) · [校准抽取复测](diagnostics/precheck_v3/TYPED_COVERAGE.json)

四个实机检查点均运行独立审计。原生主干的 12,096 个续推 token、合入后 11,991 个位置的 logits、记录的 RNG 和 KV 状态均一致。四条旁路实际生成 106 个 token，旁路运行时间合计约 5.69 秒。整个验收连同重放、双路比较和受控动作消耗 33.04 GPU 分钟。`x=-1` 越域见证和合法 `x=2` 见证分别触发保留主干与重建。这两份见证是受控证书；旁路模型输出自身保持未认证。[实机独立复核](IDENTITY_INDEPENDENT_AUDIT_ZH.md)

## 2. 历史开发三臂

rank88 的历史前缀在第 170 段把 (x^7) 的系数写成 (a+b)，精确乘积给出 (b-3a+4)。由 (x^8) 的系数独立确定 (a=3)，两者相差 −8。原先候选 `(6,31,-1)` 通过精确整除验证，保留于三个切点前。承接臂另外恢复第 210 段的有效 (a=3) 证据。

| 方法 | 正确 | 续推 token | 实付前向输入 token | 实际分钟 |
|---|---:|---:|---:|---:|
| 普通回退 | 1/1 | 20,620 | 26,575 | 23.50 |
| 双前沿无承接 | 1/1 | 14,407 | 18,821 | 16.60 |
| 双前沿承接 | 1/1 | 12,207 | 17,063 | 15.02 |

三臂共享 33 个 token 的同一条系数修正，承接另用 442 个 token。相对普通回退，承接的续推少 40.8%，实际时间少 36.1%。相对同切点无承接，实际时间少 9.5%。比较限定于一个人工绑定的历史真实错误和一个新种子。较早切点同时改变了历史证据和前缀长度，承接改变了模型看到的事实及表示。分离这两项还需要同证据紧凑桥对照。[独立成本复核](DEVELOPMENT_INDEPENDENT_AUDIT.json)

## 3. 高难新题预检与正式运行

题目按稳定哈希与预先声明的来源属性冻结，校准和正式样本互斥，并排除已有开发题的字面近重。两类来源是 AIME 竞赛题，以及 OlympiadBench 英文文本、单数值答案的代数和数论题。所有原生生成使用相同 Qwen3-4B FP16、SDPA、采样与实际容量规则。[数据与源版本](D3_DATA_FREEZE.json) · [AIME 2024](https://huggingface.co/datasets/HuggingFaceH4/aime_2024) · [AIME 2025](https://huggingface.co/datasets/opencompass/AIME2025) · [OlympiadBench](https://huggingface.co/datasets/Hothan/OlympiadBench)

8 题预检产生 111,667 个 token，7 EOS、1 真实容量终止。初版冻结得分 4/8，校准后的第二版对相同输出离线重读为 6/8。两处变化来自明确终端等式链的读出。正式题和种子在校准之前已冻结，评分器与正式方法在正式生成之前完成冻结。[预检独立审计](PRECHECK_INDEPENDENT_AUDIT.json) · [评分器冻结](COMPLETE_ANSWER_V2_FREEZE.json) · [正式方法冻结](D3_METHOD_FREEZE.json)

| 正式题层 | 正确/轨迹 |
|---|---:|
| AIME 2024 | 4/8 |
| AIME 2025 | 0/8 |
| OlympiadBench 代数 | 7/8 |
| OlympiadBench 数论 | 5/8 |
| 总计 | **16/32** |

按题目聚类，7 题两种子均正确，2 题仅一个正确，7 题均未通过冻结评分。32 条轨迹中有 10 条已读出数学对象但答案不符，6 条在读出阶段弃权。事后复核六条终端装框候选，其中四个数值与参考相同，两个不同。仅按该候选核对可得到 20/32，冻结主分为 16/32。候选核对不重新解释模型是否明确承诺答案，也不用于触发回退。独立复核重放全部 32 条冻结选择及评分，并对 26 条已交付对象逐条做有理数交叉核验。[冻结评分](bank/SCORES.json) · [独立评分复核](D3_SCORE_INDEPENDENT_AUDIT.json)

正式运行生成 501,833 个 token，最长一条 34,214 个，全部自然 EOS，无容量终止。正式原生消耗 441.41 GPU 分钟，双卡墙钟 3 小时 43 分 44 秒。实机旁路、历史开发、预检和正式原生合计 **628.95 GPU 分钟**。正式配对臂未获得准入，因而无相应 GPU 成本、修对/改错或等成本重采样数据。[正式原生独立审计](D3_NATIVE_INDEPENDENT_AUDIT.json)

| 正式漏斗层 | 数量 |
|---|---:|
| 原始记录步 | 10,070 |
| 词法或新类型事件步 | 6,024 |
| 数学表面候选，含弃权 | 9,710 |
| 有结构表达式 | 685 |
| 实际执行过核验的对象 | 628 |
| 有界数学结论 | 522 |
| 有自由变量且可形成结构的对象 | 187 |
| 具有活跃检查点的符号反例目标 | 2 |
| 可可靠绑定并进入正式配对 | **0** |
| 由当前自动证据授权的自然修订 | **0** |

两个目标分别是 `x+y=0 ⇒ y=-x` 与 `r+2=-1 ⇒ r=-3`。二者可通过形式变形检查，却缺少自然变量绑定，也都没有定位到真实的坏证明。算术层的有界结论并未打通从原题约束、推导义务到修订动作的链条。更多题可以增加答错数，当前提取机制仍需能表达真正的错误对象。[全量漏斗](diagnostics/bank/TYPED_COVERAGE.json) · [冻结选择](quality/D3_PAIR_SELECTION.json) · [独立语义诊断](D3_SEMANTIC_FAILURE_AUDIT_ZH.md)

两个复核例给出了不同的缺口。预检 P02 输出 134，确实可行，却漏掉合法的更小值 110。完整枚举发现模 17 的根为 2、8、9、15，原推理只提升了其中两个。正式 E12 的一个种子在 thinking 中验完四项原条件、得到并装框 61，正式答复重新推导时把符号写反，交付 45。二阶差分的精确校验把几何公比确定为 −3、等差公差确定为 5，唯一对应 61。前者需要完备性或最小性证书，后者需要让最终交付保持已核验结论。这两例是失败诊断。[预检有限见证](D3_P02_PROGRAM_WITNESS.json) · [正式交付漂移见证](D3_E12_DELIVERY_WITNESS.json)

## 5. 决策

当前自然语言适配器的扩大门槛未达到。保留可检验的隔离执行与双前沿后端，前端优先尝试**有明确输入契约的程序辅助验证**。适合先测的类型是有限余类、可枚举组合约束、明确递推与完整答案对象。每个程序见证只授权它实际证明的动作。例如更小可行值可撤销旧最小值，全部解的声明还需覆盖全部可能分支。对于 thinking 到 final 的重写，可以检验由完整题目约束认证的答案对象是否能在正常 EOS 交付阶段保持一致。

历史及正式失分在复核后都属于开发证据。下一轮应先在少量已知前缀上验收触发率与误修率，再冻结独立新题。同证据的普通回退、紧凑桥接和实际成本可比的重采样是质量比较的门槛。
