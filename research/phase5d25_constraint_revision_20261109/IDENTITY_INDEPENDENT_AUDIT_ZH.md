# D2.5 原生身份与隔离审计独立复核

复核了 39 个取回文件、19 个冻结输入和 4 个 D2 原始结果的 SHA-256。四个检查点与 D2 原轨迹的段落位置和实际 token 前缀一致。无提示原生续跑与 UNKNOWN 接续均逐 token 复现 D2 原轨迹，4 个检查点合计 12,096 个匹配续推 token。8 个主续跑均自然 EOS。提议段合流后的 11,991 次 logit 比较最大差为 0。运行时记录显示合流点及终止点的 KV、RNG 等状态相等，源快照未改变。复核可独立重算原始 token 数组与账本，KV、logits 与 RNG 张量的相等性取自运行时记录。[独立复核明细](D:/ACL/research/phase5d25_constraint_revision_20261109/IDENTITY_INDEPENDENT_AUDIT.json)

四个旁路审计的提示可以从冻结输入独立重建。前向账本均从缓存位置 0 开始，使用由检查点身份派生的独立种子。四条审计共生成 106 token，全部 EOS，实际增加 980 个前向输入 token 和 5.693 秒旁路时间。审计生成未进入主轨迹。

受控实验使用同一主快照和固定审计种子。带域与无域的审计输入 token 不同。三份数学证书均独立复算。对正整数命题 (x=1)，(-1) 在无域对照中可作反例，在正整数域中无效，主分支沿原生提议继续。合法见证 (x=2) 触发受控冷重放与 20 token 的核验证据桥，丢弃了 41 个原生提议 token。两条受控轨迹均自然 EOS。见证来自事先注入，模型审计输出保留为未核实提议。

## rank88 开发执行源审查

开发包的 5,905 个历史 token 与原始归档完全一致。(a=3) 的实际来源是第 210 段 token ([5140,5160))。它在错误系数出现之后写入，在数学上可由原题 (x^8) 项为零及第 167 段的 (a-3) 独立推出。

普通回退切在 5,850，保留第 232 段首次矛盾、错误的 (x^7) 系数及已写出的 (a=3)。两个受约束重放臂切在 4,309，停在第 170 段错误系数之前。三个臂都保留第 150 段较早的可行候选。只有携带臂重新写入来源已核验的 (a=3)，三个臂随后接收同一段 (x^7) 系数纠正文本。候选整除证书绑定历史生成前缀哈希，GPU 重放绑定重建的完整输入哈希。

该控制以人工绑定的历史来源和新种子运行，可观察切点与携带内容对新续推的影响。原始历史 RNG/KV 未保存，各臂保留的上下文与实付计算量也各自不同。[逐项核对](D:/ACL/research/phase5d25_constraint_revision_20261109/IDENTITY_INDEPENDENT_AUDIT.json)
