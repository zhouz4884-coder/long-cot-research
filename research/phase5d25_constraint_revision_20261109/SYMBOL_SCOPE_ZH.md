# D2.5 符号作用域与旧轨迹复核

作用域沿实际生成 token 前缀持久化。变量声明记录名称、绑定 ID、版本、定义域、角色和来源。来源带实际 token 区间、区间内字符位置、原前缀与区间内容哈希。分支内可以遮蔽外层名称，同一作用域中的局部重绑定要明确指向被替换版本。查找前提时按绑定 ID 与版本闭包。如果前提仍相关但包含已遮蔽的绑定，当前核验器无法区分同名变量，因此返回未绑定。模型提出的局部定义与假设始终保持条件资格。

在线入口使用已闭合原生段落并校验段落解码与原始 token 一致。核验既有关系时，调用者传入目标 token 区间及其段落内字符区间，避免目标用自己的定义充当前提，也避免从同一段落的后文借前提。CPU 验收包含 27 项检查，其中一项调用原有数学核验器验证非零假设的作用。在显式假设 $x\ne0$ 时，$x/x=1$ 可验证。离开该作用域后同一式子返回 UNKNOWN。

第二版仅增加三种有直接来源的规则。单变量方程要求正解时，将正值域与原方程保留在同一个目标作用域。原题明确声明变量为正时，保存这个来源支持的边界，同时保留其他条件待解析的状态。模型显式尝试另一种方法、并在四段以内逐式重述原题已核对的方程时，可以从未解析的假设分支另开局部作用域。新作用域继承原题给定，旧分支和旧主线的模型局部定义均不可见。单独出现“或者”、方程改动、超出段落窗口以及来源重叠均不足以恢复作用域。

第二版获得的 42 条条件作用域分布于三题。D2_08 的正解方程提供 28 条，D2_07 的明确正值边界提供 10 条，D2_11 的原题方程重锚提供 4 条。D2_10 的方程没有足以绑定求解域的声明。重锚后仍有局部变量缺少声明或定义域，因此部分初版的分支错误被进一步定位为缺绑定。旧数据用于开发和诊断，数学核验、证明角色、修复准入以及模型正确率另有各自的门槛。

我把默认实数域和从自然语言自动补齐前提排除在可靠核验入口之外。后续可以单独测试一种低风险增量。无分母的形式多项式若在有理系数环中规范化相同，可以验证恒等式，且无需推断实数域。若规范化结果不同，仍要有满足原题作用域的反例才能用于撤销。这个区分能检验余下覆盖不足究竟来自抽取和声明缺失，还是核验器过早要求了完整自然语境。
