# D2.5 与 D3 工作日志

## 目标与冻结边界

本轮沿着约束锚定的推理修订推进。数学对象、证明角色、作用域、修订权限和最终答案各有独立证据。研究对象是能改变修订决策的局部关系，以及同状态对照中的净修对和完整成本。已核对本地与远端基线均为 `6c3ac9ef28a1`。目标见 [用户目标](USER_GOAL.md)。

## 继承重计

按原始 SHA 复核覆盖和配对的 222 个文件，重现 48 条轨迹、460 条关系、162 条作用域缺失和 12 条无反例变量的 UNKNOWN。三条核查臂的四题输入 cue 和生成 ID 均逐题相同。原四题合计 22,940 个采样 token，Scoped 臂 29,050 个，另有 220 个强制注入 token。这个对照包含 cue 改变上下文、续推变化和核查运行的合计差异。原记录不提供 RNG 与 cue 的单独因果估计。[继承重计](INHERITED_D2_AUDIT.json)

## 离线实现、失败与修改

最初的分支作用域实现只接受显式完整声明，162 条原关系仍全部未绑定。第二版增加了可溯源的单变量正根约束、明确的变量正性条件，以及由重启措辞与原方程复述共同支持的局部分支退出。42 条取得条件作用域，120 条仍缺绑定、条件解析或适当来源。其中任何一条都没有取得完整的原题行动权限。形式多项式相等可在没有自然定义域的情况下成立，14 条取得形式证书；非零形式差异仍需合法语义才能作为反驳。[作用域复算](SYMBOL_SCOPE_DEV_REPLAY_V2.json) · [整批逐条复算](diagnostics/d2_v2/ORIGINAL_162_RECOUNT.json)

按对象类型分派。算术直接精确核验，带依据的近似只核验显示精度相容性，连续累加须有同一小计来源。显式等价和单向蕴含分别核验，跨段关系要求真实前后作用域快照。候选代回只建立在已登记的完整必要约束上，通过时只许可可行性。五条历史舍入、四条累计和九条反向对照已通过 CPU。失败复盘发现行末 `!` 被当成标点，误把 `3!` 和 `4!` 抽成常数；修复后保留阶乘原文并记 UNKNOWN。另补充了有紧邻计算依据的显示舍入识别。新旧两次 replay 分目录保存。[首次回放](diagnostics/d2/TYPED_COVERAGE.json) · [修正回放](diagnostics/d2_v2/TYPED_COVERAGE.json)

独立盲审前一版的八条判假记录，确认一处局部数值错误。该偏差不足以改变那道题的最终数字区间，而且原文采用近似语义。Phase5-B 的历史漏计例有真实组合反例，当前多项式和有理检查器缺少合适的循环排列证书。多项式 rank88 则能用整除与系数比较复核并构造修订。[独立事件诊断](DEV_FALSE_EVENT_REVIEW_ZH.md)

## 旁路审计验收

原生续推使用同一个检查点、原 RNG 和原始 prompt。旁路使用单独 prefill 和独立随机流。四个冻结 D2 检查点全部通过，续推 12,096 个 token 与原记录一致，合入后 11,991 个位置的 logit 差为 0。旁路分别实际生成了 25、53、21、7 个 token。受控正整数例中，域外 `x=-1` 被拒绝作为见证，合法 `x=2` 的反驳触发重建。两个见证为受控输入，旁路模型产生的内容单列为未认证提案。双卡总计 33.04 GPU 分钟，包含重放和对照本身。[原始运行清单](IDENTITY_RETRIEVAL.json)

## 历史开发干预

rank88 使用真实生成 ID 的前 5,905 个 token 和新的固定随机种子。原轨迹中的乘积系数 `x^7` 应为 `b-3a+4`，原文使用 `a+b`。由独立的 `x^8` 系数比较得到 `a=3`，此时差值为 −8。原始核对发现 `a=3` 的实际文字出现在第 210 段，修正先前误设的第 170 段来源，最终绑定 token 区间 `[5140, 5160)`。

普通回退切于 5,850，Scoped 两臂切于 4,309。三个方法接收相同的已核验系数修正。Carry 额外桥接切点后独立成立的 `a=3`。先前通过整除复核的候选在切点前，仍留在原前缀。三臂同卡，逐条续推到 EOS 或实际容量，计算重放、桥接和续推。该干预是人工审查的历史开发实验，历史原始 KV 和 RNG 不可复原。[准入记录](DEVELOPMENT_CPU_GATE.json) · [启动记录](DEVELOPMENT_LAUNCH.json)

三臂均自然 EOS 并正确交付 `(6,31,-1)`。唯一性另由原多项式除法的余式线性系统确认，系数矩阵行列式为 −53，评分证据在生成侧之外保存。

| 方法 | 保留的历史 token | 额外承接 token | 采样续推 token | 实际分钟 |
|---|---:|---:|---:|---:|
| GenericRewind | 5,850 | 0 | 20,620 | 23.50 |
| ScopedRebaseNoCarry | 4,309 | 0 | 14,407 | 16.60 |
| ScopedRebaseCarry | 4,309 | 442 | 12,207 | 15.02 |

Carry 在此例的付费时间相对普通回退少 36.1%，相对同切点的无承接臂少 9.5%。结果覆盖一个已知历史错误与一个新种子。早切点移除了错误推导，也改变了上下文长度。承接改变了可见证据与提示表示，后续可用同证据紧凑桥区分证据本身与序列化方式。[逐臂评分](development/SCORES.json) · [成本及源文件取回](DEVELOPMENT_RETRIEVAL.json) · [独立数学答案](DEVELOPMENT_GOLD_AUDIT.json)

## 新题校准与正式银行

按来源元数据、固定哈希及历史题目去重，预先冻结 8 道预检题和 16 道正式题。分别保留 AIME 2024、AIME 2025、OlympiadBench 文本代数与数论来源。每个正式题两个种子。校准和正式题不重叠，内容与版本逐字节绑定。8 道预检用于实测基线难度和成本，预检结果不用于替换正式题目。相同问题的种子和检查点按题目聚类。[题集冻结](D3_DATA_FREEZE.json) · [配对协议](D3_PAIRING_PROTOCOL.json)

新版完整对象评分在生成评分前冻结。21 项 CPU 测试通过。两个历史四根输出均能正确读出，整批旧轨迹开发回放为 47/48。唯一未交付的是同一句同时出现装框本金、未来金额和利率的解释。保留该弃权，随后用固定题型和固定规则统一处理新题。[读出协议](COMPLETE_ANSWER_PROTOCOL_ZH.md) · [评分冻结](COMPLETE_ANSWER_FREEZE.json)

预检纯原生生成与历史开发干预使用不同卡、不同输入和不同目录。运行重叠只改变资源占用顺序。预检第二个 worker 等待开发卡释放，再跑自己的固定成员。分别记录 worker 经过时间和阶段墙钟，重叠阶段墙钟不相加。[预检启动](PRECHECK_LAUNCH.json)

8 道预检合计生成 111,667 个 token，中位数 13,546.5，范围 2,954 至 40,850。7 条自然 EOS，1 条达到模型实际容量。worker 实际合计 98.98 GPU 分钟。初版完整对象评分为 4/8。两份终端等式链的装框标量与参考答案一致，但初版读出未交付，进入通用等式链规则的开发修正。[冻结评分](precheck/SCORES.json) · [原始取回](PRECHECK_RETRIEVAL.json)

预检语义回放发现四条 `FALSE_LITERAL` 集中在同一道题的 Markdown 枚举。行首 `- ` 被当成负号，触发了四个字面误报。此表面与显式带负号的算式分开测试，保留先前回放。[原预检漏斗](diagnostics/precheck/TYPED_COVERAGE.json)

另一个真实错例 D3_P02 选出了可行值 134，却遗漏模 17 的根 8 与 9，把可行性误当成最小性。已对原题的较小素数和模 289 的全部余类做精确有界枚举。110 是小于 134 的合法见证，完整余类为 110、134、155、179。原生第 137 步有明确错误断言，第 138 步有活跃检查点。当前自然适配缺少可执行同余与候选完备性证书，离线见证作为程序辅助路线依据。[程序见证](D3_P02_PROGRAM_WITNESS.json)

校准修正版本增加了两条保守规则。无数学定界符且行首有空格的连字符保留列表与负号歧义。四条误判复测均为 UNKNOWN，仍可检查显式数学负号。最终答案段中的完整精确等式链需复算并确认唯一装框标量，含近似、竞争答案或不相等链时仍弃权。8 条相同输出复测为 6/8，两个变化来自读出。正式方法、评分和源数据在原生正式生成前统一绑定。全部正式原生轨迹已启动。[新语义回放](diagnostics/precheck_v3/TYPED_COVERAGE.json) · [新版评分复测](PRECHECK_V2_REPLAY.json) · [正式冻结](D3_METHOD_FREEZE.json) · [正式启动](BANK_LAUNCH.json)

## 正式收尾

16 题双种子生成 501,833 个 token，32 EOS、0 cap，正式原生 441.41 GPU 分钟。独立复核通过 105 个取回记录与每题逐前向账本。正式分 16/32。10 条数学对象已交付但数值不符，6 条弃权，其中四个终端数值事后核对与参考一致。所有评分和选择均重放一致。[原始独立审计](D3_NATIVE_INDEPENDENT_AUDIT.json) · [评分独立审计](D3_SCORE_INDEPENDENT_AUDIT.json)

正式回放形成 685 个有结构表达式，其中 522 个得到有界结论。两个活跃的符号反例目标都是有效代数变形，作用域资格仍不足。自然修订准入为 0，正式同状态质量对照与等成本重采样无可运行事件。正式 E12 观察到 thinking 得到并验证 61，最终重新推导输出 45，复核确认这是交付漂移。下一轮的优先变量是程序化完备性见证和认证对象在 EOS 交付中的保持。[最终报告](D3_CLOSEOUT_ZH.md) · [E12 精确证据](D3_E12_DELIVERY_WITNESS.json)
