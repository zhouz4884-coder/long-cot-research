## 1. 目的与实现

目标是提升原生长思维链的最终解题正确率，并在同信息、全成本下验证方法增量。本轮继承 D1 已通过的原生逐 token 执行调度，分别实现受限数学核验、隔离分支和双前沿重建。

- 核验器使用有界 AST 和精确有理运算，覆盖形式多项式、整除、候选代入和域检查。证书绑定目标、前提版本、作用域和来源。
- 隔离状态保存 token、KV、下一步 logits、RNG、位置和执行身份。UNKNOWN 直接接收已经产生的无提示改动的分支。
- 双前沿分别计算失去认证支持的声明和应退役的证明文本。若结论有替代证明，保留其认证状态，同时处理失效的证明文本。重建采用 D1 同调度重放，桥接携带有完整来源和证书的事实。

新实现通过 135 项 CPU 检查，继承的 30 项检查和 600 组支持图对照重跑通过。数学核验另含 64 组独立整数多项式对照。CPU 结果支持相应接口和语义性质。真实模型结果见下文。[方法与设计决定](D2_METHOD_AND_DECISIONS_ZH.md) · [CPU 证据与源哈希](CPU_FINAL.json)

## 2. 自然覆盖

从固定版本的 MATH test 抽取 24 道题，与旧开发池、MATH-500 和 D1 接口题按规范化题干去重。20 道题为 Level 3–5，4 道为简单控制。每题两个冻结种子，Qwen3-4B FP16、SDPA、原生 thinking、batch 1，运行到自然 EOS 或真实上下文容量。实际 48 条均自然 EOS。

| 指标 | 观察值 |
|---|---:|
| 独立题与轨迹 | 24 题，48 条 |
| 有事件的轨迹 | 48/48 |
| 思维步与事件步 | 5,282 与 3,150 |
| 抽取关系 | 460 |
| 字面可核验 | 167/460，涉及 23/48 条轨迹 |
| 字面成立与字面不成立 | 158 与 9 |

| 配对事件的实际修复准入 | 0/4 |

九个字面异常集中在两道题、三条轨迹。精确复算发现五个匹配原文精度的正常舍入，四个接回上段小计后成立。D2_05 的精确乘积是 `0.0535290232`，原文 `0.053529023` 是九位小数表示。D2_15 的 `+ 0.4771 = 0.7781` 接续前段 `0 + 0.3010 = 0.3010`。按独立等式解析会漏掉 `0.3010`。数学核验器对收到的字面对象给出了正确的精确判定，失配发生在抽取和证明角色识别。

双审查由主代理和独立子代理分别阅读完整已观察前缀完成，属于离线角色审查。全九例复算是后续的局部诊断。修复许可、配对选择和所有生成在评分答案读入前闭合。当前结果衡量已定义事件与核验器的覆盖，其他类型的自然错误发生率仍有待独立标注。[全量覆盖审计](COVERAGE_AUDIT.json) · [独立重计](INDEPENDENT_COVERAGE_RECOUNT.json) · [盲审记录](ROLE_REVIEWS.json) · [九例复算](INVALID_LITERAL_FAILURE_MODES.json)

## 5. 评分读出问题

D2_10 两个种子的最终响应均列出 `2±√3` 与 `1±√2`。精确因式分解验证原四次式为

\[
(z^2-4z+1)(z^2-2z-1)=z^4-6z^3+8z^2+2z-1.
\]

两个二次式各有两个实根，且无公共根。固定 LastBox 对 `\quad` 分隔的四框只读末框，对逗号分隔的相邻四框返回歧义。事后集合复核仅补核这两条。结合 46 条主评分通过，答案内容口径为 48/48，作为独立次要诊断。后续评测要在生成前冻结完整对象交付和多框集合读出规则。[精确复核](FINAL_OBJECT_READOUT_AUDIT.json)

## 6. 自己的判断与下一门槛

隔离、回退、反例核验和携带有效事实分别有直接近邻。可测试的贡献是把有作用域和版本的证明级撤销连接到原生思维链的语义与文本两个前沿，验证清除失效证明后能否保留合法进展。最关键的效果对照是相同证据的紧凑桥接和普通回退。当前自然账本只登记封闭表达式求值，尚未形成跨步证明依赖，因而无法充分检验这个贡献。[五篇原文对照](PRIOR_ART_SCOPE_ZH.md)

本轮最明确的失配来自数学对象边界。下一轮先复用现有原始前缀做离线短试。需要让抽取器辨别完整算式、跨段累加和近似值，显式绑定变量、必要前提与适用范围。近似算术先从有明确精度的样本建立受限核验。作用域不完整时继续记 UNKNOWN。

我的假设是，高阶长链的质量瓶颈更多来自错误建模、错误变量绑定和不完整的修订传播。封闭算术可以给出可靠低成本证书，覆盖的却主要是已正确解题过程里的局部计算。验证这个假设可先从 162 条缺 scope 的候选中按冻结规则抽少量做独立标注，找出可授权的真实失败或假反例，再拿少量新的高难题做同证据配对。原生基线的数学答案内容在本批已到顶，需要用独立难度或题型规则提高下一批的辨别力。

下一轮有效进展的判据为更高的可行动覆盖、受控的错误撤销率，以及实际同证据配对的净修复。评分层、证据层和最终解题质量分别保留指标。
