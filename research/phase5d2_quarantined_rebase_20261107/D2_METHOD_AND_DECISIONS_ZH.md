# Phase5-D2 方法、决策与可证伪假设

本阶段继承提交 `059a462f06b8`。目标仍是长思维链最终解题正确率，以及完整成本下相对强基线的可重复增量。D1 的八题原生续推和数值调度检查保持原始口径。

## 1. 对本次外部审查的判断

采纳先做原生隔离、实际受限核验和自然事件覆盖，再做条件性配对的顺序。优先测清算法在哪些自然状态上有合法动作。CPU 检查和执行一致性分别回答实现问题，解题评分才回答质量问题。

采纳双前沿。撤销一条证明后，结论可能仍有其他有效支持，因此不能把失去支持的声明集合为空作为删除反思的理由。对于错误反例，也只能说明这次反驳失败，原答案仍需独立认证。

采用完整状态复制作为正确性参考。保存 token、KV、下一步 logits、RNG、位置、thinking 状态和运行身份。成本包括复制、解析、核验、重放以及丢弃提案。当前没有 clone、crop 或 offload 加速结论。

拒绝提案后采用提案已消耗的 RNG 状态，并加入受限核验失败原因。两项改变都记录在输出中。恢复原位置和原 RNG 后重复采样可能生成同一提案，已有 CPU 例重现该行为。

## 2. 数学对象和行动边界

原生状态写作

\[
s_t=(P,u_{1:t},K_t,\ell_t,\rho_t,m_t,\eta).
\]

其中 \(\ell_t\) 是下一 token logits，\(\rho_t\) 是随机状态，\(m_t\) 是思考和终止状态，\(\eta\) 绑定模型、分词器、执行调度和采样配置。

提案分支从独立状态副本生成 \(R\)。核验对象包括命题、证明角色、作用域、全部必需前提及其版本。四类行动分别由合法反驳、失效证明、非法反例和 UNKNOWN 驱动。UNKNOWN 路径接收已经生成的分支。原生一致性只在未改提示和采样协议的专用实验中检查。

支持图前后的两个前沿为

\[
F_{\mathrm{sem}}=\operatorname{Cert}(G)-\operatorname{Cert}(G'),\qquad
F_{\mathrm{text}}=\{\operatorname{span}(j)\mid j\text{ 已被核验为应撤销的证明}\}.
\]

裁剪取两个非空前沿中最早来源之前的合法完整步边界。具体实现还检查真实 token、原生思考状态、来源哈希、当前版本和证书冲突。这个策略是可检验的保守候选，没有最优成本保证。

桥接只携带有完整现行证据的事实及其来源。首次自然适配仅登记封闭表达式的精确求值。例如某段出现 \(3\times4=12\)，可认证这个算术关系。原题中的对象建模、变量身份或最终答案不随之获得认证。

## 3. 额外区分字面核验与证明角色

等式可能出现在举例、假设、引文或反证中。一个字面等式为假，不自动授权删除对应推理文本。

因此覆盖统计单列抽取、字面可核验、符号作用域绑定、核验有结论和可行动错误。`actionable_role_candidate` 仅为词法候选，`role_certified` 初始始终为 false。自然修复需要两个独立审查者仅阅读完整已观察前缀，先于 Gold 和干预输出核对来源、断言角色和撤销范围。分歧直接不授权修复。

这个角色审查使第一批修复属于有离线角色许可的条件性诊断。审查由主代理与独立子代理分别完成，尚无外部人工标注。若今后算法需要自动运行，还必须另外验证自动角色判定的可靠性。不能把这项审查成本和额外信息隐藏在端到端结果中。

## 4. 冻结实验与成本口径

覆盖集为 24 道新题、两个种子，共 48 条轨迹。依照外部难度、题型与稳定哈希抽样。20 题为 Level 3–5，4 题为简单控制。新题与旧 MATH-500 分池及 D1 接口题去重。全部题目保留，正常运行到 EOS 或实际模型上下文容量保护。

所有原生结果收齐后，按 `PAIRING_PROTOCOL.json` 的固定优先级、题号、种子和步号选择最多四个不同问题的事件。选择与角色审查完成后再运行配对。答案仅用于最终统一评分。

第一组比较原生续推、普通上下文核查、无域约束隔离核查、带域约束隔离核查和无提示改动的 UNKNOWN 一致性。只有出现合法修复事件才进入回退、承接、重启、同证据桥接和重采样对照。相同问题的多个检查点不作为独立题目计数。

本版提案解析器只接受非空变量集合的完整 JSON 赋值。封闭数值等式没有可提交的变量反例，这类目标在提案检查中必然 UNKNOWN。它们能比较审计提示和原生续推，能测试分支接收的一致性，无法识别 scope 拒错的增量。上下文核查采用相同的参考 fork 接口，实际复制成本会计入，它的计时代表该参考实现。

自然账本当前把每个封闭左侧表达式的求值作为独立声明，尚未建立原题对象、中间变量和跨步证明的语义依赖。因此自然适配中的语义前沿通常为空。若在错误等式刚结束时干预，最近合法回退点与最早错误证明之前的边界也可能相同。实现记录切点、桥接和实际前缀是否等价。相同条件产生相同结果时，不能据此证明双前沿或完整支持保护已有额外收益。该创新候选仍需要真实的语义绑定与依赖覆盖。

重采样的完整轨迹具有不同的自然长度。预算比较需要记录目标成本以下和以上的实际完成轨迹组合，给出成本区间。相同输出上限或相同采样次数不足以宣称成本匹配。

## 5. 预先记录的失败解释与下一项核查

若作用域覆盖低，先分清表面表达式不支持、缺少量词或前提、角色不确定和检查器资源保护。扩大训练无法直接补齐来源语义。

若 Scoped 与 Unscoped 相同，可能是自然样本没有受显式域约束影响的反例。需要先报告这种事件是否实际出现，再讨论 scope 模块有无增益。

若 RebaseCarry 不能超过相同证据的紧凑桥接，可能是收益完全来自新证据信息，或者裁剪破坏了仍有用的隐式状态。检查真实 cut、桥接来源和复发位置后再决定下一轮设计。

若桥接保住了认证算术却未提高答案正确率，可能是封闭表达式求值与真正解题依赖之间距离过大。自然语言中的对象和变量绑定将成为下一项待核验假设。

修复共用的撤销证据包还引用原错误等式及其旧值。它们作为被撤销的证据记录有合法来源，但模型仍可能在后续错误地复制这些数字。若清理旧历史后仍复发，应区分历史 KV 的影响和新撤销提示再次暴露错误值的影响。检查只看新采样后缀中的实际使用，提示包自身引用旧值不计作复发。

若自然错误机会很少，报告覆盖范围与条件性效果。下一轮是否扩大数据由实际机会和伤害共同决定，当前不预填论文效果或创新成立的结论。
