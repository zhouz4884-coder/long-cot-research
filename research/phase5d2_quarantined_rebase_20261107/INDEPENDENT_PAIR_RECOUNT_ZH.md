# D2 配对运行独立重计

按取回清单复核了 69 个文件的字节长度和 SHA-256，并检查了四个入选源结果、检查点前缀和运行环境身份。20 个输出均到达 EOS、闭合 thinking、未触及上下文容量。本次复核只使用文件字节、运行记录、token ID 和账本。

四题的无提示原生续跑和 UNKNOWN 接续都逐 token 复现了覆盖阶段的原生结果。运行记录显示，从提议段结束到终止前，11,991 次比较中的 RNG 状态均相等，最大 logit 差为 0，终止 RNG 也全部相等。提议段内部的逐步 logits 未序列化，比较范围从提议段合流点开始。

三个有审计提示的核验臂在每道题上生成了完全相同的提示 token、提议 token 和完整续跑 token。它们在四道题上的完整 token ID 均与无提示原生续跑不同。12 次检查均因没有适用的反例变量而返回 UNKNOWN，全部沿同一已生成分支续跑。两条错误闭合等式的候选角色均由两位审阅者标为 UNKNOWN，另外两题没有待否定的证明候选。四题均未满足修复资格，修复臂生成数为 0。
