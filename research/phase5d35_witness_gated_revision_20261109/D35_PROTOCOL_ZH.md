# D3.5 见证门控修订协议

## 对象与权限

研究目标是最终交付正确率。D3 的正式冻结值为 16/32，结构表达式 685，自然修复准入 0。D3.5 将候选、极值、全称、根集完备性与终局改口作为独立对象。完整题干模板只接收明示约束和目标角色。模板范围外保留 UNKNOWN。已观察数值须能追到实际生成 token 与完整前缀，核验状态另行记录。[继承审计](INHERITED_D3_AUDIT.json) · [候选归档](CANDIDATE_ARCHIVE_ZH.md)

两候选极值支配须同时具有完整可行性。具体反例只撤回所检命题。有限搜索以题干编译后的程序、当前声明与明确操作预算为输入，按实际计算计费。程序回执必须重算。只有独立证明唯一目标值或完成有界全域的证书才能直接交付答案。后验来源拒绝进入在线门控。[离线实测与反向控制](OFFLINE_DEVELOPMENT_AUDIT.json)

## E12 已观察证书与终局交付

固定使用种子 20261110 的最后一个开放 thinking 检查点，长度 3,848。阶段只向 worker 提供题干、该时点 token 与原 RNG。先运行未改写的原生续推和同证据提示，两条都以自然 EOS 或模型实际容量停止。原生完整续推结束后，LastThoughtAnswer 仅读取真正生成的 thinking 终点。直接工具交付只接收可执行题干契约。WitnessGatedCommit 则从实际原生草稿重新抽取最终候选，若它与检查点内已观察、经完整约束及唯一性认证的候选冲突，在发布前拒绝草稿并交付证书值。已采样、被拒的原生最终段仍计费。工具交付不记成模型 EOS。

## E15 观察见证、回退与承接

固定种子 20261110、活跃步 464 之后的前缀。前缀内原生候选通过逐位约束核验后才能支持支配证书。先验证当前已观察的极值主张和两个候选。普通回退退到最近可复核的完整段落边界。作用域臂的目标级前沿包含同对象的已证伪全局极值主张，以及能从原文绑定、精确比较且确实错误的排序依据。切到较早的完整原生段落，承接被切掉的可行候选或在必要时重新明确其认证级别。该适配器复用原生重放与边界规则，当前前沿覆盖目标层的声明与排序依据。

同证据提示、普通回退和作用域回退接收相同的短见证正文。正文只提供可行性与支配关系。三臂间主要变量是保留历史与切点。各续推使用同一原检查点 RNG；更早切点的臂也使用此共同的后续随机状态。原生参照接收原上下文。五臂拥有同一套工具权限，直接搜索基线执行相同契约下完整有界搜索，模型回退臂使用已经获得的局部证据。完整搜索可以直接交付时，必须报告它的竞争力。

GPU 使用一次共享教师强制原前缀重建，并在多个合法切点克隆状态独立续推。每个臂保留切点等价重放和切点后实际前向的明细。总计算只计一次共享重放。旧冻结历史中被切除的 token 单列，不重复算作本轮生成。实际验证、搜索与回放的 CPU 时间和操作数保留。切点间的重放计时与真实线上自回归前缀的耗时分开解释。

## 独立确认门槛

两个主实验及所有离线窗口属于开发证据。D3 已有样本的正式分 16/32。只有在同工具条件下，候选仲裁或回退呈现可复验且优于简单交付的收益，才冻结新题并开展独立比较。若直接工具解覆盖开发题，应先限定新增机制的适用题型，并找出工具只给局部反例且无法廉价独立求解的实例。
