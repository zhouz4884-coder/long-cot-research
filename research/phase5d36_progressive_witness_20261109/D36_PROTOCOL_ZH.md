# Phase 5-D3.6 有限验证预算下的证据棘轮

## D3.5 哪里没拉开差距

D3.5 的 E15 只有一个历史错例和一个续写 RNG。三个干预臂都同时拿到数值排序、可行性说明和继续寻找的指令，无法分辨哪部分有用。切点后，作用域回退比普通回退多 2,495 个采样 token，正确交付相同。直接程序的完整求解加重验约 0.104 秒。E12 的末框读出也能交付正确值。现有结果足以说明两个实际原生失误可以修正。主问题是同等信息和权限下，持续状态维护有没有独立价值。[D3.5 收尾](../phase5d35_witness_gated_revision_20261109/D35_CLOSEOUT_ZH.md)

## 状态与权限

令 $C_P(w)$ 为原题的可信点谓词，$f_P(w)$ 是经目标绑定的值。每张认证回执绑定原题、目标、候选出处、前缀、检验版本与成本。最大化维护 $L_t=\max\{f_P(w):C_P(w)=\mathrm{FEASIBLE}\}$，最小化对称。已认证不可行或被严格支配的终局候选可触发修复。临时试探性数字、缺失语义、来源不一致和预算耗尽保持 `UNKNOWN`。可行界只授权下一义务，例如寻找更高的可行值或证明该范围无解。只有对向完整目标界闭合或完整目标证明允许自动认证全局答案。

普通候选点核验及持续策略共享访问上限。主实机 $K=16$，底层算术上限 1,024，最多四次状态反馈，终局修复最多一次，记录重试中的全部采样。单次验证的工作单位与 CPU 时间单列。`K=0/4/8/16/32` 的 CPU 比较描述局部接口预算行为。只有实际施加各预算并重新生成才能形成模型准确率曲线。有限点查询的工具启发式与原生模型加点核验均作为对照。保留允许完整求解时的独立 `DirectSolver`。8,229 次是既有实现的数字扩展次数，不是理论下界。

## E15 双检查点试验

早期固定步 316 的已观察闭合段落，含 `1011235 < 303369` 的错误自然语言比较，长度 19,902。后期固定步 464，长度 24,532。两处均来自公开 D3 同一条原生轨迹。原始采样 RNG 加两枚提前确定的新续写种子，共六个同题前缀与 RNG 单元，分开列出。前缀输入、题干与 RNG 包按 SHA-256 冻结。历史档案没有导出这两个位置完整 logits/KV，因此实机测量重放后的哈希及形状，并通过原生续写完整 token ID 与发布的原生轨迹比对。

| 臂 | 信息与动作 |
| --- | --- |
| NativeContinue | 同原生上下文直接续推 |
| NeutralReminder | 同命令骨架，要求核对是否有更大候选 |
| ClaimOnly | 明确指出先前结论尚无依据，省略更大的具体值 |
| NumericWitness | 提供已观察数值的正确排序，说明排序本身不证明可行 |
| VerifiedWitness | 在同一位置给出可行下界和精确支配，生成中无进一步反馈 |
| ProgressiveWitness | 与 VerifiedWitness 的初始提示完全相同，只在候选状态实质变化或终局冲突时介入 |
| EveryStepAudit | 初始提示相同，对所有可抽取的明确候选提交运行审核，状态变化才可反馈 |
| InvalidWitnessControl | 拒绝伪造的见证来源，使用与中性提醒相同的安全回退提示和配对 RNG |

无效候选 `10112357` 独立点验应在末位违反条件，`10112358` 应合法。已知最优值与事后档案只在实机输出关闭后用于评分。终止于自然 EOS 或模型实际容量。计入按位置一次共享的原生重放、实际 KV 状态操作、提示、正常生成、已拒草稿和额外修复。策略间比较同时给自然工作量与部署时各自所需工作，不给共同账本重复计费。

## 决策标准

E15 是因果开发病例。主对比为 ProgressiveWitness 与 VerifiedWitness，在相同初始提示下比较可复验的正确交付和成本。普通提醒若也成功，结论保留在“见证提供何种额外信息”。无原生正确分母时，不能估计改错风险。若机制可靠且相对强基线达到可复验的质量增量，或在同质量下减少真实部署成本，再冻结 12–24 道开发之外的独立问题。独立验证分有限点接口与完整工具两种场景，以题目为统计单位。任何大规模多模型实验以独立小规模结果为前置。
