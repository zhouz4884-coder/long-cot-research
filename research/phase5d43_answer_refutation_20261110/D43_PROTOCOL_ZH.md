## 抽样和隔离

- 固定原生 Qwen3-8B thinking 轨迹的发布版本 `c34143c92856d9b90fdb9c808c7e66070dcab9a1`。只纳入 2009–2023 AIME，排除可以映射的历史开发题和规范化同题。再按题目 ID 的 SHA-256 固定排序取前 32 个独立题，四个 draw 固定为 0、1、2、3。选择规则不使用生成正文、长度、作者正确率、金标或参考解答。运行前冻结精确盐、题号、输入问题规范化哈希、源分片和不可识别旧题范围。[固定数据源](https://huggingface.co/datasets/suryadv/qwen3-8b-aime-2009-2024-16x/tree/c34143c92856d9b90fdb9c808c7e66070dcab9a1)
- 题面规范化为 Unicode NFKC、连续空白压成一格、去首尾空白、Unicode casefold，再做 SHA-256。该方法给出规范化字面去重。题面转述或从不同来源重排的等价题另查，无法证实的旧题范围写入局限。
- 输出盲化视图只保留原题、生成文本、官方终止字段和稳定身份。评分阶段才打开参考答案。作者正确率、参考解析和题号的答题目录字段不得作为抽取输入。原题及轨迹原文存于本地工作区。公开审计保存分片身份、来源范围、检查收据与可发布衍生汇总。
- 完整样本以 32 个题为分母。四次抽样在同题内配对。EOS、长度截断、终止未知、缺失与解析失败分列，截断的样本不能当作正常交付。正文缺少明确 thinking 分界时保留未知。若报告有分歧子集，按事先定义的无标签规则列出并保持完整样本结果。

## 方法与判据

对每道原题 (P)，以题目请求的完整对象 (T(P)) 为键。候选保存其值、来源段落、绑定范围和交付完整性。单独记录草稿到 final 的正确→错与错→正确。候选数值相同的不同写法先做普通等价合并。若同值来自不同对象，保留作用域差异，防止格式变化冒充数学修复。AIME 题目的整型答案合同只是外层格式，不能证明 `m` 与 `m+n` 是同一对象。

核验器的输入包括预先审阅的原题必要条件 (c)、类型化候选 (a) 与它们的原题绑定。只有 (P\models c(T(P))) 的依据成立、绑定完整且实际检查得到 (\neg c(a))，才允许剔除该候选。候选提供的中间式可以作为待核查见证，不能自行建立必要条件。未知与无冲突均保留。剩余单一候选仍沿用普通选择状态，除非另有完整证明。若所有可选项都被排除，记录冲突并沿用冻定回退，避免从空集合宣称正确。

先从原题制作候选值盲的条件提案和证明范围，再通过隔离的审阅绑定作用域。每题最多执行两项独立必要条件，逐项记录 CPU 时间和检查过的候选数，重复或无效调用的工作也纳入收据。必要条件直接推出完整答案时，单列为简单直接复核的解题证据。由现成完整求解器给出的答案不进入 Verifier-Only。

比较原生 draw 0、draw 0 末尾明确读出、固定池多数票、同权限普通直接复核、作用域反证选择。报告固定池 final-only 和含合格 thinking 候选的两个离线 oracle 上限，区分新增候选与选答收益。所有池选择器共享相同已付费样本，生成成本与后处理成本分开计量。主指标为题级实际正确率，附每臂修对与改错、空池、选择失败、正确候选覆盖、可核查的证书覆盖和错误候选拦截。换答案但最终变错仍计为损失。

至少四个独立题必须有能区分现存候选的非格式证书，相对最强同权限实际基线至少要有两个题级净修正，并审阅所有候选误杀，才进入独立的 12–24 题确认。确认样本和种子在推理前锁定。若门槛落空，收尾报告逐例解释是候选池没有正确项、反证权限不够、原题绑定失败，还是普通对照已解决。若开展新生成，各臂同样允许原生终止，仅共享安全上下文边界，全部标记实际终止原因和完整成本。
