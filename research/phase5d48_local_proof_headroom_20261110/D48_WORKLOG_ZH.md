# D4.8 工作记录

| 遇到的问题 | 尝试和结果 | 对决策的影响 |
|---|---|---|
| D4.4–D4.7 的任务与分母不同 | 逐份核对公开回执，分开 D4.4 实机和三个 Qwen3-8B 归档批次。官方键争议、重复抽样与缺交付单列。 | 末答不一致与中途错误分别测试。保留旧 draw 8–15。 |
| 形式核验和回溯有直接先例 | 学术检索接口不可用，脚本回退返回 HTTP 429。改用会议原文与作者预印本核对具体算法及实验。 | 把贡献问题缩到同权限、同证据的增量，回溯和符号核验作为已知构件。 |
| ProcessBench 可看步骤，但不能精确复现自然前缀 | 核对公开字段及论文的数据重排流程。另定位 MathArena 原始消息归档并逐题对齐到 HMMT 题面。 | ProcessBench 只适合校准。当前模型归档也只提供文本证据，在线回放需另取原生状态。 |
| 候选库的 Qwen3-8B 缺失 | 两年仅对模型、题号、抽样编号和题面做独立投影。选双方均完整覆盖且参数量最小的公开推理模型 QED-Nano 4B，固定第 0 抽后才开消息。 | 两年结果分层。模型名与配置相同只证明归档键相同，历史服务修订和 EOS 保持未知。 |
| 题源侦察有预暴露 | 侦察者在找来源时见到解答摘录。另请未见解答的人只审两年原题 20 道并决定 9 道。完整解作者与归档审查者交叉分配，归档末答和金标分开。 | 保留预暴露事实与职责边界。选题和各盲审仍有各自可核对的冻结。 |
| 原本看似要广搜的题有短完整解 | 宽三路径先实现转移并与小规模 DFS 对照，随后推导偶数宽闭式。圆周合并用三次势函数替代状态枚举。其余题用匹配、凸几何、下集、分块和计数。 | 对所有题保留同权限的最强普通控制。不能以原始枚举的耗时作为局部策略基线。 |
| 简单计时未覆盖准备成本 | 分列一次计时、操作名称及若干重复 CPU 计时。证明发现、作用域审查和反例设计的人工耗时没有逐条统一测量。 | 用强完整控制已覆盖来裁定准入，不外推模型端到端加速。 |
| 局部证书可能错误授权 | 测试逆向箭头、错目标、伪来源、试探、越界算式、并发用尽预算和截止时刻。用旧 Schur、椭圆、六边形做作用域控制。 | 只有所有前提通过且结论在同一点为假才允许反驳。数学正确与原句作用域各自核验。 |
| 两份早期回执含有断言之后的思维文本 | 发现 2025 两条回执在整个早期窗口上计算哈希。保留原回执，再用精确断言结尾截断，重签并复算全部四条。 | 四条反例结论一致。使用新回执报告文本边界，原回执只支撑离线观察。 |
| 早期局部错误和末答错误没有对应起来 | 开金标前冻结九个末答框和四个早期算术回执。核对三条错误末答，分别找到无完整推导的末尾猜测、切割方向遗漏和行访问合并假设。 | 前四条算术错误全部自行纠正。后两条反例是评分后的机制解释，独立准入保持 0。 |

我对成本问题的猜想是，短竞赛题看似有庞大搜索空间，常能通过题面结构把完整目标压缩为短公式。早期错式频繁也可能很快自修。这两种情况都会限制局部证书转成模型收益。可证伪检查是换到拥有明确候选验证协议且规模可变的独立问题，先实测最强普通完整解，再查模型错误是否持续并由同证据短反馈纠正。[普通筛查](D48_ORDINARY_SCREEN_ZH.md) · [归档规则](D48_ARCHIVE_AUDIT_RULES_ZH.md)
