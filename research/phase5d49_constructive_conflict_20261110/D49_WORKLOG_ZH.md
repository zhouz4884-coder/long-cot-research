# D4.9 工作记录

| 问题 | 尝试 | 结果与决策 |
|---|---|---|
| 可核验构造题的来源与历史轨迹是否足够 | 核对 ComBench 论文、作者仓库和数据卡，并核对 NLCO 与 ConstraintBench。 | ComBench 有 50 条构造题，但作者公开源未找到逐次生成文本。NLCO 有稳定公开版本。ConstraintBench 论文提供方法和统计，当前未找到正式数据发布。 |
| 公开构造 JSONL 同行含隐藏字段 | 固定资产和 Git 对象，独立只投影题面、提交格式及身份。被审查的投影无参考构造和可执行作者代码。 | 3 个论文案例先排除，三人分工覆盖其余 47 条。另排除论文提及的 IMO 2025 P6 和 D3.7 重复使用的车覆盖原题。 |
| 构造权限可能和原题证明混淆 | 对每题分别记录原题量词、固定构造尺度、给定目标、可核验的具体冲突及完整对照。 | 冻结 10 个原题身份，各取一个正式固定构造。单个合法构造、局部状态和最优性证明按不同权限计。 |
| 常规求解器慢容易制造虚假成本差 | 砖块先独立建立 CP-SAT 和几何复验，再用轴向分层构造。 | 固定边长 20 的通用 CP-SAT 8 秒找到 35，已证明下界为 30。独立普通构造精确给出 30。 |
| 大棋盘的局部证书可能比全局输出快，但已有规律 | 先用完整精确模型生成候选，再检验是否存在独立格点不变量。 | 骑士题的宽 81 固定实例被 CP-SAT 解出；解的条纹结构可压缩为模 3 行规则，并有不变量证明。 |
| 饱和横条的初始构造有错 | 发现所有横条左对齐会让右侧整列可再放竖条，改成左右交替，并保留精确饱和检查。 | 更正后的构造达到独立下界。普通对照必须同时交付合法构造和下界证明。 |
| 作者表达式包含压缩构造及不同尺度的键 | 普通回执先冻结。另用有界数据语法展开参考列表，木条参考有固定五键查表，另加精确白名单。 | 10/10 独立全量核验。原题键与固定构造目标分列，未执行作者验证器。 |

目前的猜想是，规则长度和维度适合确定性核验的竞赛构造题，也常有极短的结构式完整构造。要验证模型局部修复的边际价值，应区分人工已推导的构造、通用求解器的动态成本和模型没有见到构造时的能力。只要这个差距仍能由同权限普通构造消除，额外生成的收益就需另找真实任务复测。
