# D5.0 三态修订的一步梯度实证

D4.8 的四条早期精确错误都由模型自行纠正。D4.9 的十个固定构造都由普通结构式完整覆盖。两轮结束后，将问题改成训练信号是否能在相同数据下，更好地学习何时推进修订、拒绝错误改口和保持正确状态。已有理论只完成了 CPU 代数校验，本轮要看真实检查点的一步结果。[D4.8](../phase5d48_local_proof_headroom_20261110/D48_CLOSEOUT_ZH.md) · [D4.9](../phase5d49_constructive_conflict_20261110/D49_CLOSEOUT_ZH.md) · [原梯度审查](../algorithm_mechanism_20261105/transition_anchor_math_audit.md)

## 样本与权限

以原题为单位分训练批 $B$、独立方向批 $B'$、留出 $H$。同时保留自然归档诊断与可控前缀的结果，两者不能混为覆盖率。每个自然断言须在已见前缀中完整出现，先锁定判断和原题证据再解封答案键。未知作用域、已自行改正、缺共同前缀及终止未知都单列。原生续写和人工编制的反事实前缀分别标记。

E 是拒绝已被原题证伪的旧值并传播有效修订。W 是拒绝会破坏正确已提交状态的错误修订。C 是前提未改变时维持已验证的依赖。留出对用同一可见前缀，给出两个同语义粒度的可比较续写。主要测试相同 token 长度的候选，长度不同的单列。前缀尽量保留必要状态并隐藏新求的下游结论，避免从末尾直接读答案。

## 四个主臂

主样本使用相同 $B$、同一初始 LoRA 参数 $\psi_0$ 及共同 teacher-forced 支持。参考方向分别是 $B'$ 的均匀全链 CE、仅标记答案跨度的 CE、以及 E/W/C 分组等权的目标续写相对反例续写的负对数概率裕量。设 $L_j$ 为对应方向损失，$g_j=\nabla_\psi L_j$。一个方向单独做一次反传，再测主批每个 token 损失的方向导数

$$
s^{(j)}_t=\langle g_j,\nabla_\psi\ell_t\rangle .
$$

主对照是均匀监督、使用 VCORE 全链参考方向、仅答案锚定、三态锚定。后三臂用相同的 $D_{\mathrm{KL}}(q_j\Vert u)$ 预算求 Gibbs 权重。权重从反向图分离。主结果使用同学习率的一步 SGD，再做同参数更新范数诊断。全链方向保留作者方法的核心效用，统一 KL 和原始 SGD 属于本实验控制。作者固定温度和方差缩放若运行则单列。[VCORE 原文](https://aclanthology.org/2026.acl-long.1298/) · [作者源码](https://github.com/coder-gx/VCORE)

## 先检验数值，再读取留出

固定种子、基础权重、LoRA 子空间、输入 token 和工具版本。开发阶段先用可微小模型的逐 token 梯度和两个差分尺度核对符号、精度及恢复，再在小型真实 Qwen 控制检查显存和数值误差。eps、学习率、KL 以及留出阈值只用开发控制确定。每条方向梯度和每次扰动前向都计费。三方向夹角、权重 ESS、最大权重及恢复字节一并报告。参数空间同范数与等策略 KL 分列。

正式留出同时报告 E、W、C 的实际边际变化、线性近似、二阶剩余、零步与重复噪声。若真实变化低于已量化噪声，或 W/C 有确定伤害，则不给额外训练授权。只有跨独立题的实际方向改善且通过伤害对照，才在另批问题验证自然 EOS 的最终正确率。小试的 NLL 或裕量只能支持机制结论。
