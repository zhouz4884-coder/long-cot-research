# 方法内核与可检验创新：先明确证据覆盖，再谈修复策略

2026-11-06。工作名SCOPE-Rebase。**已实现CPU受限证据内核和原生检查点执行器；尚未实现通用自然图/G或端到端修复策略，不能把本规格当成已测算法收益。**

## 1. 真正要区分的四件事

1. 某个算式算对了。
2. 该算式在当前对象、前提、定义域、版本下，确实证明了指定结论。
3. 新证据确实反驳了这条结论或这条论证，而不只是一个别处成立的陈述。
4. 逻辑状态修好后，模型当前文本/KV是否仍含失效推导，怎样合法重建。

核心贡献候选在2–4的可靠衔接。单独算术检查、OR-of-AND闭包、fork、回退和事实保留均已有强先例，不能靠组合名宣称创新。

## 2. 完整覆盖证书

一个证书至少绑定：canonical conclusion及实体、scope assumptions、原题规则许可、实际必要前提及版本、checker版本/输入摘要、可重放见证。Checker必须重建实际所需支持，而不能信任模型自报的premise列表已经完整。

例如可信定义是y=x+r，只有x的独立证据不足以保住整个y。缺r、作用域不兼容或rule license不明确时应UNKNOWN。反之一个结论有另一条完整有效证明时，单条论证失效不应撤掉它。

对数值相等的判断也必须区分身份：5可以是某算式的结果，却不能仅因为2+3=5就认证任意subject“y=5”。当前CPU实现已覆盖这个必要反例，但没有替代自然语言语义解析。

## 3. 反驳目标限定

\[
G(e,j)=PASS\iff e\text{ 的见证有效、scope适用，且确实反驳指定 }j.
\]

不能将“e这个陈述为真”直接作为“e否定j”的证书。对普遍断言，一个满足原域约束的真实反例可使其失效；域外例子不能。单点满足一个恒等式也不能证明恒等式或多项式整除。

论证失效与结论被否定分别更新。证书冲突进入隔离状态，不任意宣布某一根为假，也不从不一致推出全部结论。

## 4. 支持状态与神经文本分别更新

支持闭包是最小不动点，防止无根循环自证。撤回后记录L（失去所有认证支持的声明）与I_text（失效论证/反思的文本跨度）。二者并不相同。

一个声明仍有替代证明，L可以为空，但被撤回的坏证明文字仍在native前缀中；这时“逻辑无需删除声明”不等于“模型状态无需处理”。回退候选由需要退役的文本与失效支持共同确定，再映射到已观察安全步边界，不声称最小成本最优点。

仅carry当前仍完整认证的规范内容、条件和依据，重新prefill/逐token重放形成新状态；不迁移旧后缀KV。桥接是否真的让模型复用成果，需要同证据、同读出阶段的真实配对试验。

## 5. 隔离反思的角色及RNG陷阱

隔离提案可以作为主内核的接入结构：先保留主前缀，再让候选反思在独立分支产生，核验后才决定是否接纳。它不是另一个凭名称成立的创新，需与Sherlock等近邻和等成本再采样比较。

若错误反思已进入主文本，即使ledger拒绝它，也不能只改标志；其文本可能需要退役。若反思在隔离分支，则丢弃分支可以避免它直接进入主上下文。

但“拒绝后完全恢复前缀和RNG，再照原样采样”可能再次产生同一段反思。实际策略必须声明如何处理：继续使用消耗后的随机流、记录合法拒绝依据、或明确再采样。它们都会改变后续分布，不能声称拒绝动作保证零伤害。任何重采样机会和被拒调用都计成本，并给普通再采样强基线。

当前D1只核无干预的状态/RNG复原；没有偷偷把上述拒绝策略接入质量结果。

```text
    → 单列失效文本与失效支持

```

完整系统须与Continue、普通Audit、GenericRewind、RebaseNoCarry、FullRestart、同工具直接核验/交付、等成本独立续写比较。模块对照再共享相同G事实和carry内容，检查重建本身有无增量。

## 7. 指标与可证伪结论

优先全题最终正确率及修复/伤害；辅助false challenge accept/reject、UNKNOWN/覆盖率、partial-support false preservation、支持误删、复发及完整成本。不能用低误接受但几乎全UNKNOWN包装成功。

若精确工具已给完整答案，直接交付基线优于回退，说明无需在该类状态增加复杂策略；若只有oracle父边界有效，说明自然提取/G尚未过门；若同证据普通回退/重采样一样好，则没有新增结构增量。D0/D1结果只为这些试验提供可信基础，不预言数个百分点提升。
